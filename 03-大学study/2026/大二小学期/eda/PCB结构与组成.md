# PCB 结构与组成

> 本节内容对应视频 P9，讲解 PCB 的物理结构与基本组成元素，为后续 PCB 设计打下基础。

---

## 1. 什么是 PCB

**PCB** = **Printed Circuit Board**（印刷电路板）

- 是电子元件电气连接的**提供者**
- 通过铜箔线路实现元器件引脚之间的连通

---

## 2. PCB 板的分类（按基板材料）

| 类型 | 特点 |
|------|------|
| **高频板** | 适用于高频信号场景 |
| **金属基板** | 包括铝基板、铁基板、铜基板，散热好 |
| **铝基板** | 常见于 LED 照明等需要散热的场合 |
| **双面板** | 入门课程主要学习的类型，顶层 + 底层 |
| **多层板** | 更多层数，布线更灵活，成本更高 |

> 本课程以 **双面板** 为主进行学习。

---

## 3. PCB 的组成元素

### 3.1 导线 (Trace)

- 本质是 PCB 上 **细长的铜箔**
- 用于连接两个不同元件的引脚
- 连接关系由原理图的 **网络 (Net)** 决定
- **不同网络的导线不允许相交**（短路）
- 布线时导线可推挤、环绕，但不能短路
- 粗细可调，通常用于 **信号线** 布线

### 3.2 铺铜 (Copper Pour)

- 一整块大面积的 **铜皮**
- 用于对特定网络进行连接
- 典型用途：
  - **GND 网络** — 铺铜形成完整地平面
  - **电源网络** — 大电流 / 散热
- 一般在布完信号线之后进行
- **十字连接 (Thermal Relief)**：焊盘通过十字形与铜皮连接，防止焊接时散热太快导致虚焊
- **直连/填充 (Fill)**：铜皮与焊盘直接相连，无过渡，用于大电流场合

### 3.3 填充 (Fill / Copper Area)

- 与焊盘 **直接相连** 的铜皮
- 中间无任何过渡（区别于十字连接的铺铜）
- 用于：
  - **大电流走线**（如电源线）
  - **整片区域布线**
  - **定位/固定焊盘**（不需要焊接的焊盘）

### 3.4 过孔 (Via)

- 用于连接 **不同层之间的信号线**
- 可以理解为 **贯穿 PCB 层间的导线**
- 也可用于器件的 **固定或定位**（如 M3 螺丝孔）

#### 三大类型

| 类型 | 说明 | 价格 |
|------|------|------|
| **通孔 (Through Hole)** | 贯穿顶层→底层，最常用 | 低 |
| **盲孔 (Blind Via)** | 顶层→中间某层，不影响其他层布线 | 中 |
| **埋孔 (Buried Via)** | 中间层→中间层，表面看不见，走线干扰最小 | 高 |

> **通孔**最常见；**盲孔**不影响其他层布线；**埋孔**走线干扰最小但价格最高。

### 3.5 焊盘 (Pad)

- 焊接元件时需要的 **裸露铜皮**
- 用焊锡将元件固定到 PCB 上，实现电气连接

#### 两种类型

| 类型 | 适用元件 | 特点 |
|------|---------|------|
| **通孔式焊盘 (Through-hole Pad)** | 直插元件（如晶振、排针） | 中间有孔，插针穿过焊接 |
| **表贴式焊盘 (SMD Pad)** | 表贴元件（如电阻、电容、IC） | 无孔，一块方正的铜皮，引脚贴在上面焊接 |

### 3.6 丝印 (Silkscreen)

- 相当于 **PCB 上的注释**
- 直接打印在 PCB 表面（阻焊层之上）
- 作用：
  - 识别元件的位置、数量、型号
  - 放置个人标志 / Logo
- 表现为 PCB 上的 **白色文字和边框**

### 3.7 阻焊 (Solder Mask)

- 覆盖在铜层上的 **油墨层**
- 作用：
  1. **保护铜层** — 防止氧化
  2. **防止短路** — 焊接时只有焊盘裸露
- 需要焊接的焊盘位置会进行 **开窗处理**（没有阻焊）
- 阻焊层比焊盘略大一圈
- 常见颜色：**绿色**（最普遍）
- 对比：铜腐蚀板没有阻焊，焊接时容易短路

---

## 4. 总结

| 元素 | 英文 | 主要功能 |
|------|------|---------|
| 导线 | Trace | 信号线连接 |
| 铺铜 | Copper Pour | 地/电源网络，散热 |
| 填充 | Fill | 大电流直连 |
| 过孔 | Via | 层间连接 |
| 焊盘 | Pad | 焊接元件 |
| 丝印 | Silkscreen | 注释标识 |
| 阻焊 | Solder Mask | 保护防短路 |
