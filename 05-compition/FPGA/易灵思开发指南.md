- # 工程
	- ## 工程创建
		在 Create New Project 面板中设置相关参数，器件由芯片来决定。
		（1）工程名“Name”,
		（2）指定工程所在的位置“Location”,
		（3）“Family”设置器件家族“Tianium”
		（4）Device 设置为“Ti60F225”
		（5）Timing Mode 设置为 I3
		- 指定TOP_module
