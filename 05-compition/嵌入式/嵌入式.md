# 嵌入式

## 理论部分

### MCU 选型

> [!quote] 一个原则：花最少的钱，做最多的事

在确定项目需求的情况下，一般按照下面的顺序选择合适的 MCU：

1. **选内核** — 选择哪种内核的芯片。内核越高，意味着功耗也越高
2. **选引脚** — 选择多少引脚的芯片。引脚数量决定了资源（外设）的多少，也影响价格
3. **选存储** — 选择多大 RAM 和 FLASH 的芯片。FLASH 越大，价格越贵
4. **选供货** — 还要考虑所选型号是否采购容易、供货是否稳定

### 芯片基础概念

- 存储器映射
- 寄存器

### 支持的 4 种驱动库

| 驱动库 | 说明 | 优缺点 |
| --- | --- | --- |
| **基于寄存器编程** | 直接操作寄存器 | 最底层，效率最高，但开发慢 |
| **SPL**（标准外设库） | ST 官方早期标准库 | 封装适中，已逐渐被 HAL 取代 |
| **HAL**（封装 + 抽象） | 配合 CubeMX 生成代码 | 可阅读、可封装、硬件覆盖广；**运行效率较差** |
| **LL**（Low Layer，更少抽象） | 轻量底层库 | 适合**频繁 IO** 操作 |

> [!note] 实际开发中的选择
> - 现代开发更喜欢用 **HAL（配合 CubeMX）** 和 **LL**
> - 遗留问题：AI 开发常常**不经过 HAL**、直接修改代码 —— 那它实际使用的是哪种库？属于寄存器直接操作，还是 LL？

## 需要补充学习

- **定时器溢出**：测量 PWM / 555 的笔记只用 `CNT = 0` 清零。16 位 ARR 在 1 MHz 计数下最长约 65 ms，低频信号会溢出而测错，需要学习溢出中断计数。
- **定时器时钟树**：PSC、ARR 公式的前提是理清 APB 时钟与定时器时钟的关系（APB 分频后定时器时钟可能自动倍频）。
- **中断与共享变量**：ISR 与主循环共享的变量需加 `volatile`；笔记中“中断里不能调用显示函数”的原因（共享总线、非可重入）尚未讲清。
- **GPIO 总线复用与锁存器**：PC8–15 同时驱动 LED 与 LCD，PD2 控制 74HC 锁存器。“灯光打架”的根因就在这里，需要学习锁存器时序。
- **I2C 协议细节**：起始 / 停止、ACK / NACK、24C02 写周期（约 5 ms）、页写、随机读与当前地址读。
- **UART 进阶**：空闲中断（IDLE）、DMA 循环模式、环形缓冲区，用来替代笔记中的 `RxCount %= 7` 与定时器判帧方案。
- **DAC / ADC 与查表法**：DAC 由 `TIM_TRGO` 触发、采样率与奈奎斯特准则、ADC 采样时间、过零法测频的误差。
- **分压与数字电位器**：MCP4017 的 7 位 128 级、后级负载对分压比的影响。
- **555 定时器**：多谐振荡器占空比 $D=\frac{R_1+R_2}{R_1+2R_2}$，理解 R40 / R39 如何影响频率与占空比。
- **HAL 与底层**：寄存器 / LL / HAL 的取舍；AI 生成代码绕过 HAL 时实际用的是哪种库（本笔记“遗留问题”）。
- **MSPM0 平台**：SysConfig、时钟源（MFCLK）、与 STM32 HAL 的对比。目前 06 目录只有零散笔记，需要系统补齐。
- **国产替代**：GD32 / MM32 与 STM32 的 pin-to-pin 与 HAL 兼容性需要实际验证。
