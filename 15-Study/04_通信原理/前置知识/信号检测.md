你提到的三个概念——能量检测（Energy Detection）、CFAR（恒虚警率检测）和 YOLO 频谱目标检测——都属于无线信号检测领域。

它们之间存在联系，但并不是同一种算法。可以把它们理解为三个不同层次的检测方法：

* 能量检测：判断某个频段有没有信号。

* CFAR：在噪声背景变化时，判断某个频率位置是否存在目标信号。

* YOLO：将频谱图作为图像，检测其中的信号目标，并识别其位置和类别。

### 一、能量检测（Energy Detection）

### 1\. 基本思想

能量检测是一种经典的频谱感知方法。

假设我们有一个无线接收机，需要判断某个频段是否被其他无线设备占用。

可以建立两个假设：

H_0:y\[n\]=w\[n\]H_1:y\[n\]=s\[n\]+w\[n\]

其中：

* ：不存在目标信号，只有噪声。

* ：存在目标信号，同时包含噪声。

* ：接收信号。

* ：噪声。

能量检测的核心思想是：计算接收信号的能量，然后与设定阈值比较。

检测统计量：

T(y)=\\frac{1}{N}\\sum_{n=0}^{N-1}|y\[n\]|^2

判决规则：

T(y)
\\mathop{\\gtrless}_{H_0}^{H_1}
\\lambda

其中 是检测阈值。

* ：判定存在信号。

* ：判定不存在目标信号。

### 2\. 直观理解

![Adaptive double threshold energy detection based on Markov model for cognitive radio - PMC](https://images.openai.com/static-rsc-4/FzUkoCNOuR7EIQJoDOnxNW8LGRbJFG5gF10KjXfbam1W8qBsYaCtjDed04Y7dWefkJM_7QNb5Jrmi6PUUDumKYO_1BRtujc7V0pJkWgvp-uYSCwFGb582-va6Y3L3OSkqLvNzAYa0huQEogLGVvIA_2GsD5GhWgNYV4BVUxwT0kRUJTJBHtlTXUA--o76QhH?purpose=fullsize)

假设某频段的噪声功率为 -90 dBm，而接收信号功率为 -65 dBm。

如果设置合理的检测阈值，就可以区分噪声和信号。

但这里存在一个问题：

如果噪声功率发生变化，原来设定的阈值可能不再适用。

这就引出了 CFAR。

### 二、CFAR（恒虚警率检测）

### 1\. 什么是 CFAR？

CFAR，全称 Constant False Alarm Rate，即恒虚警率检测。

它是一种自适应门限检测方法。

与普通能量检测使用固定阈值不同，CFAR 会根据待检测单元附近的噪声和背景功率，动态调整检测阈值。

其目标是：

在噪声和背景环境变化时，尽可能维持预设的虚警概率。

这里需要理解两个概念：

* 虚警（False Alarm）：实际没有目标，却判断存在目标。

* 漏检（Miss Detection）：实际存在目标，却没有检测出来。

### 2\. CFAR 的基本结构

![GitHub - Photonf22/RadarDetection: This is a repository for Udacity's Computer Vision course on radar object detection. · GitHub](https://images.openai.com/static-rsc-4/fxKoE4ySpraHeatdF9DzuANZw5r-cHi4ntUP33pvIGNQy73MaKYr4D6laTTXfWXvI2rtqA3JQWfpHLhkfhe6FykNj43_nFFT7ESFHcbRcC1Q-tJOc58PBCUTlC_1wr__m2N4Fd4vnLKspska1M1GUGi9HHmBUBSPq6qI40q5uCYiUBZd_YQawk-CvW1hnUjk?purpose=fullsize)

以最常见的 CA-CFAR（Cell Averaging CFAR）为例。

它将频谱中的数据划分为：

| 区域             | 作用                |
| -------------- | ----------------- |
| CUT            | 待检测单元             |
| Guard Cells    | 保护单元，避免目标信号污染噪声估计 |
| Training Cells | 参考单元，用于估计背景噪声     |

工作流程：

* 选择一个待检测频率单元 CUT。

* 从周围参考单元估计背景噪声功率。

* 根据预设虚警概率计算检测阈值。

* 比较 CUT 与阈值。

* 输出检测结果。

其基本判决形式：

P_{\\text{CUT}}>\\alpha P_{\\text{noise}}

其中：

* ：待检测单元功率。

* ：局部背景功率估计。

* ：门限调整系数。

### 3\. CFAR 有哪些类型？

| 类型      | 特点               |
| ------- | ---------------- |
| CA-CFAR | 对参考单元取平均，适合均匀背景  |
| GO-CFAR | 取两侧较大的噪声估计值      |
| SO-CFAR | 取两侧较小的噪声估计值      |
| OS-CFAR | 对参考单元排序后选择特定位置的值 |

它们主要区别在于背景噪声的估计方法。

### 4\. 能量检测与 CFAR 的区别

| 对比    | 能量检测      | CFAR       |
| ----- | --------- | ---------- |
| 核心    | 信号能量与阈值比较 | 自适应门限检测    |
| 阈值    | 通常固定或预先标定 | 根据局部背景动态调整 |
| 噪声变化  | 比较敏感      | 适应能力较强     |
| 计算复杂度 | 低         | 相对较高       |
| 典型用途  | 频谱感知      | 频谱目标检测     |

注意：CFAR 不是能量检测的替代品。CFAR 本身也需要检测统计量，例如频谱功率或能量。两者可以结合使用。

### 三、YOLO 频谱目标检测

这是一个更偏向深度学习和计算机视觉的研究方向。

YOLO（You Only Look Once）是一类单阶段目标检测算法。

传统的能量检测和 CFAR 主要回答：

> 某个频率位置是否存在信号？

而 YOLO 可以进一步回答：

> 频谱图中有哪些信号？它们分别位于什么频率范围？具有怎样的时频形态？

### 1\. 基本思想

将无线信号转换成瀑布图或语谱图，再将其输入 YOLO 网络。

![Spectrogram Data Set for Deep-Learning-Based RF Frame Detection | MDPI](https://images.openai.com/static-rsc-4/__8QDoIV-NTCzVy2lfcAmhJmUx_0qSpF7Pd65YoOQUDHtNFAroWyoGIJDpVMZp4UHXmwpVqhv8M60IdZKSXTzf9AhJKvbiinZpWp1QRnvhH_WlQWyxc7Na9S9p6klKooGhkmV7ZUTo-FpzlfWA_kso97Vpzpz4sRB0dYFZoQgGV5B9zgGd8oRi2p8HaYBrob?purpose=fullsize)

整个流程：

SDR 接收 IQ 数据

STFT / FFT

生成时频图或频谱图

数据标注

为信号目标标注边界框和类别

YOLO 网络

特征提取 + 目标定位 + 分类

检测结果

目标位置、频率范围、时间范围、类别

### 2\. YOLO 能识别什么？

例如，一张频谱瀑布图中可能同时存在：

* 持续存在的窄带信号。

* 突发式信号。

* 不同带宽的信号。

* 不同时间出现的信号。

* 多个频段同时存在的信号。

YOLO 可以通过边界框（Bounding Box）标记目标。

![Spectrogram Data Set for Deep-Learning-Based RF Frame Detection](https://images.openai.com/static-rsc-4/bhbt__0IcBT8vc5EMjnHVZ2FnrkMMjeDKydfzbKciquehIISsvO0GM5qYGBeKF07k9hQaPllvpOkZon28d5ZY9iCwoYthfqyO-xBpFLuF2z02numoc0y7MYxNNSUWiHTfcpBpfV7EYtlaIIPAKRimQNrNVE1OARrgqztPQSgxCeZWS8nCEqxGB-rRK7Zui59?purpose=fullsize)

一个目标框可以表示为：

B=(x_c,y_c,w,h)

其中：

* ：目标框中心坐标。

* ：目标框宽度和高度。

将图像坐标映射回物理坐标，就能得到：

* 信号开始时间。

* 信号结束时间。

* 信号中心频率。

* 信号带宽。

不过，YOLO 是否能够区分具体调制方式，取决于训练数据和类别定义。单纯检测到一个信号框，并不意味着已经识别出它的调制方式。

### 六、我认为值得关注的研究问题

这三个方向实际上可以形成一个很有意思的研究课题：

基于传统信号处理与深度学习的智能频谱感知。

可以考虑如下技术路线：

* 使用能量检测建立传统基线。

* 使用 CFAR 提高非均匀背景下的检测适应性。

* 使用 YOLO 识别复杂时频环境中的多个信号目标。

* 对比三种方法在不同信噪比、信号重叠和噪声变化条件下的性能。

需要注意，三种方法的输出任务并不完全相同，比较时应统一检测目标和评价标准。

一个重要的研究思路：传统算法负责提供可解释的检测基线，深度学习负责处理复杂特征和多目标场景。 不必认为 AI 一定比传统算法好，真正有研究价值的是明确各自的适用边界，以及能否通过合理融合获得更好的性能。
