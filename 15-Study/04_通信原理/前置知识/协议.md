你列出的这五种信号，实际上代表了五类很有代表性的无线电信号接收与协议解码任务。它们可以作为一个 SDR 多制式信号接收与智能识别平台 的典型应用场景。

这里需要区分两个概念：

* 调制识别（Modulation Classification）：判断信号采用 AM、FSK、GMSK、Chirp 等什么调制方式。

* 协议解码（Protocol Decoding）：在完成信号解调后，进一步恢复比特流、帧结构和有效数据。

前者解决信号是什么，后者解决信号传递了什么信息。

### 一、五种典型信号的技术原理

### 1\. NOAA APT：气象卫星图像接收

![NOAA Satellite Signals With a PVC QFH Antenna and Laptop  : 9 Steps (with Pictures) - Instructables](https://images.openai.com/static-rsc-4/o5XBPgLabkapYbzSTnJafZwrrBgkltsGkEg2w5sn2tUve3WaxkhAtcysTeVM6lN3Jqma6jgPTZ6UUBBYLIgGH699d4-yZvVfodlzU6omPwdY1r1FRjQhs6lZG1_LAsryU9hgAHj9qszHieVmbVjwTP3ehwIS1xuVuioe9i_lWsESA2WwjBUktrWr8yqPeRfq?purpose=fullsize)

NOAA APT（Automatic Picture Transmission）

一种模拟图像传输系统，通过卫星向地面广播气象图像。接收后可以重建灰度卫星云图。

主要技术流程：

IQ\\rightarrow FM解调\\rightarrow AM解调
\\rightarrow 行同步\\rightarrow 图像重建

这里有一个需要纠正的地方：NOAA APT 通常采用 FM 射频传输，解调后得到随图像亮度变化的模拟视频信号。因此不能简单理解成直接对射频信号进行 AM 解调。

关键技术：

* FM 解调：恢复图像亮度信息。

* 行同步：定位每一行图像的起始位置。

* 灰度映射：将信号幅度转换为像素亮度。

* 多普勒补偿：应对卫星运动引起的频率变化。

### 2\. AIS：船舶自动识别系统

![HM-5900 (10") AIS B類 10吋船舶自動識別系統 (XF-1069B)  - 錦輪電子](https://images.openai.com/static-rsc-4/9IIYF_mbFYsljVMkMy6p8MK3iKT7HH8Pm3s4EFga2Raq8C9_IMupW-OFs0FHS9DkBXpmW67NSDjmw_Vtl3a3x_eOlQ9Oc1qN5CGyaEYxZUB_70TnhHCIxmIG2awfhN1FSGY8R_MhLVlc0PLZZvUPtCrFn6rsm41ttjNXTR29mMPFfNHwSGt28TwjJLvDlIdv?purpose=fullsize)

AIS（Automatic Identification System）

船舶通过无线电交换身份、位置、航向、航速等信息。

AIS 工作在 VHF 海事频段，主要使用两个信道：

* AIS 1：161.975 MHz

* AIS 2：162.025 MHz

主要技术流程：

IQ\\rightarrow GMSK解调\\rightarrow NRZI解码
\\rightarrow 去填充\\rightarrow CRC校验

几个关键概念：

| 技术           | 作用           |
| ------------ | ------------ |
| GMSK         | 高斯最小频移键控调制   |
| NRZI         | 非归零反相编码      |
| Bit Stuffing | 比特填充，避免帧定界混淆 |
| CRC          | 循环冗余校验       |
| TDMA         | 时分多址接入       |

AIS 的一个难点是多个船舶可能同时发送信号，接收端需要处理信道竞争、帧碰撞和信号重叠。

### 3\. FT8：弱信号数字通信

![WSJT-X 3.0.0-rc1 リリース : 向島ポンポコ日記](https://images.openai.com/static-rsc-4/LTj3sQThwNIAiQM1XZZ0RTZ0dsjBkIYvUZVVMfuyaDXP337keGJG3s-teKTLb68YPYNP7J3nE81HiHiJF1fTADAd8foGkuHpqzxTtzGFjXcfnbjsPBMzmOEfDQGH223rAKnLTQG1BX4FhTZ4vBOsLg6D-E1wyTszgSxCnL4hXKoy-cUcTSrLgTpulaUYHtx-?purpose=fullsize)

FT8（Franke-Taylor design 8-FSK）

业余无线电中的数字通信模式，主要用于弱信号环境下的信息交换。

FT8 的技术特点：

* 8-FSK：使用 8 个不同频率表示符号。

* 每个符号携带 3 bit 信息。

* 单个符号持续时间约 0.16 秒。

* 一个标准传输周期约 15 秒。

主要流程：

IQ\\rightarrow 频率同步\\rightarrow 8FSK解调
\\rightarrow LDPC译码\\rightarrow CRC校验

这里值得注意：

FT8 的弱信号接收能力不仅来自 LDPC 纠错编码，还依赖严格的时间同步、频率同步、结构化消息和相干/非相干信号处理等技术。

你列出的 LDPC 软判决是重要环节，但并不是完整的 FT8 解码过程。

### 4\. LoRa：低功耗远距离通信

![Susceptibility of LoRa Communications to Intentional Electromagnetic Interference with Different Sweep Periods](https://images.openai.com/static-rsc-4/TiJbkg0CarlX-tBZLgkeQhmlxEd9vOR2IYFyudlKsX_NB_dG0rsXzo6h_HoHKWI4SYCe-do7qylv1iTim8YTq85DPbUCcwl5xqJH_qFJxcNsRYc6cQ4-AgE_aWWektFgSQ7Uc8Be4ilzPGo7lne4Dw6HGvM9OQcAoRDff82iP2RMz30D0ygAoo4fJrT2zrUK?purpose=fullsize)

LoRa（Long Range）

一种基于 Chirp Spread Spectrum（CSS，线性调频扩频）的无线通信技术。

LoRa 与前面几种信号有明显区别。

它不是简单地通过不同载波频率或相位表示数据，而是通过改变 Chirp 信号的频率变化规律表示符号。

核心技术：

Dechirp + FFT

接收到的 Chirp 信号与本地参考 Chirp 相乘，完成解扩（Dechirp），再进行 FFT。

原本的线性调频信号经过解扩后，可以形成明显的频域峰值。

r(t)\\cdot s_{\\text{ref}}^\*(t)
\\rightarrow FFT
\\rightarrow 峰值检测

其中：

* ：接收 Chirp。

* ：本地参考 Chirp。

* FFT 峰值位置：用于判定符号。

重要参数：

| 参数  | 含义   |
| --- | ---- |
| SF  | 扩频因子 |
| BW  | 信号带宽 |
| CR  | 编码率  |
| CF  | 中心频率 |

LoRa 的一个研究难点是盲参数估计，即在事先不知道 SF 和 BW 的情况下识别信号参数。

### 5\. 探空仪：气象遥测信号接收

![2024-10-02 | Apie meteorologinį balioną ir atmosferos radiozondavimą – Meteo LT](https://images.openai.com/static-rsc-4/pFm8w_jHTjtdLRiRBoaU7TXT4KZHT0m0tjXZI7mM6GnWhmoHarkJ-05pWyzwN9yDb4T3Pdrm4RWXT8G-EcDqvMvQLSp9CRKnN1UZ0kWJXgVkbsfdyjCSX1vVBv8LIdLI-N_opdUjcVUzUQV6EdgJCpB4AXxFfeIl4tMnw_ye_cpkdjJj1cS7yukZM8EZP23E?purpose=fullsize)

探空仪（Radiosonde）

由气球携带升空，测量并传输温度、气压、湿度、定位等气象数据。

典型技术流程：

IQ\\rightarrow FSK/GFSK解调
\\rightarrow 比特同步\\rightarrow 帧解析
\\rightarrow 数据恢复

关键难点：

* 气球持续运动，导致接收信号频率发生变化。

* 高空环境可能产生信号衰落。

* 不同厂商使用不同的遥测协议。

* 需要识别帧结构、校验字段和数据编码方式。

这里需要补充：探空仪并不只有一种统一的调制和协议格式，具体取决于型号和厂商。

### 二、五种信号的技术对比

| 信号       | 调制方式       | 核心算法         | 最主要的技术难点 |
| -------- | ---------- | ------------ | -------- |
| NOAA APT | FM 射频传输    | FM 解调、图像重建   | 行同步、频率漂移 |
| AIS      | GMSK       | NRZI、CRC、帧解析 | 多用户信号重叠  |
| FT8      | 8-FSK      | 同步、LDPC      | 极弱信号接收   |
| LoRa     | CSS        | Dechirp、FFT  | 参数盲估计    |
| 探空仪      | FSK/GFSK 等 | 解调、帧解析       | 多普勒、衰落   |

### 三、如果构建一个统一 SDR 平台

这五种信号可以整合到一个统一的接收处理框架中。

![PPT - Recognition and Adaptation in PHY Layer for Cognitive Radio PowerPoint Presentation - ID:9410523](https://images.openai.com/static-rsc-4/YHfkqUyGhBllcIrZYb17PnMcdSwc92_0j8OGtp9ag0Y724fJVGxxROOsS96Mpghe11yGqbAZNbYhcRLriP7hFw7KxBsxUpf6vrpq1tw4SeSAaY9k8JN_qWT3DPoQaqoayzYG0oj_rK-HnDDfYLxP-ZoG2t7c5lmnuLpHkFPxrDemD6KOxNWSyc8lWwXhNdav?purpose=fullsize)

我建议采用分层架构：

第一层：射频采集

硬件层

USRP B210 → 射频接收 → ADC → IQ 数据流

第二层：通用信号处理

DSP 层

* 数字下变频 DDC

* 滤波与抽取

* 频率同步

* 瀑布显示

* 信号检测

第三层：信号识别

AI 层

* CNN 调制识别

* YOLO 频谱目标检测

* 信号参数估计

* 协议类型分类

第四层：协议解码

应用层

* NOAA APT 图像重建

* AIS 信息解析

* FT8 消息解码

* LoRa 数据解析

* 探空仪遥测解析

这里有一个重要的工程设计原则：不要让 YOLO 或 CNN 取代所有传统信号处理模块。

更合理的方式是：

* DSP 负责频率变换、同步、解调等确定性任务。

* AI 负责复杂场景下的识别、分类和辅助参数估计。

* 协议解析器负责恢复标准化的数据结构。

### 四、建议的学习与项目顺序

如果以 USRP B210 为实验平台，我建议不要一开始就同时做五种协议。

可以按照技术难度和知识积累顺序安排：

| 顺序  | 项目       | 学习价值                |
| --- | -------- | ------------------- |
| 1   | NOAA APT | 理解模拟信号解调与图像重建       |
| 2   | AIS      | 理解数字调制、帧同步和协议解析     |
| 3   | LoRa     | 理解 Chirp 扩频和 FFT 检测 |
| 4   | FT8      | 理解弱信号处理、同步和纠错编码     |
| 5   | 探空仪      | 综合运用调制识别和协议解析       |

这些项目适合在合法接收、公开广播和自建测试信号的范围内开展。实际发射实验应遵守当地无线电频率和发射许可规定。

### 五、从研究角度看，这些项目有什么价值？

我认为这组技术可以归纳为一个更有研究价值的方向：

面向异构无线信号的智能感知、调制识别与协议解码。

它涉及三个层次：

* 信号层：如何从复杂电磁环境中发现信号？

* 特征层：如何判断信号的调制方式和参数？

* 协议层：如何从信号中恢复有效信息？

这也能把你前面学习的数字下变频、瀑布显示、能量检测、CFAR、CNN 和 YOLO 联系起来。

一个值得尝试的研究问题是：

能否构建一个由传统 DSP 与深度学习共同驱动的多制式无线信号识别系统，使其能够从未知 IQ 数据出发，逐步完成信号检测、调制分类和协议类型识别？

这比单独实现一个 CNN 分类器更接近完整的无线通信研究系统。
