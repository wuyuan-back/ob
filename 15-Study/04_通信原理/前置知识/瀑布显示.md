\*\*瀑布显示（Waterfall Display）\*\*是软件无线电（SDR）中一种常见的频谱可视化方式，用于观察无线信号的频率分布及其随时间的变化。

简单来说：

* 普通频谱显示：观察某一时刻，不同频率上的信号强度。

* 瀑布显示：连续记录多个时刻的频谱，并按照时间顺序排列，形成类似瀑布的图像。

通常可以这样理解：

| 坐标   | 含义            |
| ---- | ------------- |
| 横轴 X | 频率（Frequency） |
| 纵轴 Y | 时间（Time）      |
| 颜色   | 信号强度（Power）   |

颜色通常代表不同的功率大小：

* 深蓝色：信号较弱。

* 绿色：信号中等。

* 黄色、红色：信号较强。

具体颜色映射取决于软件设置。

### 二、瀑布显示是如何产生的？

其核心是对输入信号进行连续的 FFT（快速傅里叶变换）。

基本处理流程：

接收数字信号

ADC / SDR 数据流

分帧处理

将连续信号划分为多个数据块

FFT 变换

计算每一帧的频谱

计算功率谱

通常转换为 dB 标度

逐行绘制频谱

形成瀑布图

假设第 帧信号为：

x_m\[n\]=x\[n+mH\]w\[n\]

其中：

* ：窗函数。

* ：相邻帧之间的移动步长。

* ：时间帧编号。

对每一帧进行 FFT：

X_m\[k\]=\\operatorname{FFT}\\{x_m\[n\]\\}

然后计算功率谱：

P_m\[k\]=20\\log_{10}(|X_m\[k\]|+\\epsilon)

实际功率谱也常采用 表示。

最后，将每一帧的频谱作为一行，根据功率大小映射颜色，连续排列起来，就形成了瀑布显示。

### 四、结合你的 USRP B210 项目

在你搭建 OFDM 收发系统时，瀑布显示非常有用。

例如，你可以通过 GNU Radio 的 QT GUI Waterfall Sink 观察接收信号。

重点观察：

* 中心频率是否正确： OFDM 信号是否出现在预期频率附近。

* 信号带宽： 占用的频率范围是否符合 OFDM 参数设置。

* 信号稳定性： 是否存在频率漂移。

* 突发传输： 发射端发送数据时，接收端是否出现对应的信号。

* 干扰情况： 是否存在其他频率上的干扰信号。

另外，瀑布显示还可以辅助观察频偏，但精确测量载波频偏通常需要进一步进行同步和频率估计算法。

最后记住一个区别：

| 显示方式              | 主要回答的问题          |
| ----------------- | ---------------- |
| 时域波形（Time Domain） | 信号随时间如何变化？       |
| 频谱显示（Spectrum）    | 信号包含哪些频率成分？      |
| 瀑布显示（Waterfall）   | 不同频率上的信号随时间如何变化？ |

从通信工程角度看，瀑布显示本质上就是一种连续短时傅里叶变换（STFT）的时频可视化形式。它把原本难以直观观察的无线信号时频变化呈现出来。
