你提到的应该是基于 CNN（卷积神经网络）的调制方式自动识别（Automatic Modulation Classification，AMC）。
==二维CNN==


它是 AI + 通信领域的一个典型研究方向。核心思想是：不再完全依赖人工设计的特征和判决规则，而是将接收到的无线信号转换成时频图像（语谱图），再利用 CNN 自动提取特征，判断信号采用了哪一种调制方式。

例如，系统接收到一段未知信号，希望自动判断它属于：

* BPSK

* QPSK

* 8PSK

* 16QAM

* 64QAM

* 2FSK

* 4FSK

* OFDM 等

这个过程就是调制方式自动识别。

### 一、整体实现原理

1\. 接收无线信号

USRP / SDR 获取 I/Q 数据

2\. 信号预处理

归一化、分帧、去噪等

3\. 时频变换

STFT → 生成语谱图（Spectrogram）

4\. CNN 特征提取

卷积、池化、特征映射

5\. 分类判决

Softmax 输出各调制类别概率

6\. 输出识别结果

### 二、为什么要使用语谱图？

语谱图（Spectrogram）是通过短时傅里叶变换（STFT）得到的时频表示。

普通 FFT 只能告诉我们信号包含哪些频率成分，却不能很好地反映这些频率成分随时间如何变化。

STFT 则将信号分成多个时间窗口，对每个窗口分别进行 FFT。

数学表达式：

X(m,k)=\\sum_{n=0}^{N-1}
x\[n+mH\]w\[n\]e^{-j2\\pi kn/N}

其中：

* ：FFT 点数。

* ：帧移。

* ：窗函数。

* ：时间帧编号。

* ：频率索引。

通常使用幅度平方生成语谱图：

S(m,k)=|X(m,k)|^2

再转换为 dB：

S_{dB}(m,k)=10\\log_{10}(S(m,k)+\\epsilon)

这里有一个值得注意的地方：

语谱图和你刚才学习的瀑布显示，本质上有很大联系。

两者都可以通过连续的 FFT 结果构建时频图。区别主要在于使用目的和显示方式：

* 瀑布显示：主要用于无线电频谱监测和信号观察。

* 语谱图：通常作为机器学习模型的输入特征。

### 三、CNN 如何识别调制方式？

CNN 原本常用于图像识别，例如识别猫、狗和汽车。

在调制识别中，我们把语谱图当成一张二维图像。

CNN 主要完成三个任务：

![Neural Network Diagram Generator — CNN Visualizer | SciFig](https://images.openai.com/static-rsc-4/7Ie77snMNLqDxf_6K9KiIN4lzN8QrLgWTOYc4T-xceUJjDjJ0Wfv0wihOdlZSmn-SJ01sxRao4Rd8PESfJatfkyGlRhw_DB9Zl9Q_2-OhFG0tBJbxlLCqmMxBlZgxPgeMJSR9tkIqPxr3dsEz9EmSuX-8CfoS5kWMphb_XF0ptN5EohXcwM7KSPXyUy9LCrI?purpose=fullsize)

1\. 卷积层（Convolution）

提取局部特征，例如：

* 频率变化规律。

* 时频纹理。

* 信号能量分布。

2\. 池化层（Pooling）

降低特征图维度，减少计算量，并保留重要特征。

3\. 全连接层（Fully Connected）

综合提取的特征，输出调制类别。

例如，Softmax 最终输出：

| 调制方式  | 预测概率 |
| ----- | ---- |
| BPSK  | 3%   |
| QPSK  | 86%  |
| 8PSK  | 5%   |
| 16QAM | 6%   |

模型最终判断为 QPSK。

这里的概率是模型输出的分类置信分数，并不意味着真实识别正确率就是 86%。

### 四、这个方向有哪些关键技术难点？

实际无线通信环境远比理想仿真复杂。

| 影响因素      | 对识别的影响     |
| --------- | ---------- |
| 低信噪比（SNR） | 信号特征被噪声掩盖  |
| 载波频偏（CFO） | 频谱位置发生偏移   |
| 相位偏移      | 信号相位特征发生变化 |
| 多径衰落      | 信号时频结构发生变化 |
| 采样率偏差     | 时频特征发生变化   |

因此，不能只让 CNN 学习理想环境下的信号。

研究中通常需要构建不同 SNR、频偏和信道条件下的训练数据，测试模型的泛化能力。

### 五、结合你的 AI + 通信研究方向

我建议把这个方向拆成三个层次：

| 层次  | 研究内容          | 涉及知识                  |
| --- | ------------- | --------------------- |
| 第一层 | 基于语谱图的调制识别    | 数字通信、STFT、CNN         |
| 第二层 | 低信噪比条件下的识别    | 深度学习、信号检测、数据增强        |
| 第三层 | 真实 SDR 环境下的识别 | USRP、GNU Radio、实时信号处理 |

可以采用以下技术组合：

* MATLAB：生成 BPSK、QPSK、QAM 等调制信号。

* Python：使用 NumPy、SciPy 生成语谱图。

* PyTorch：搭建 CNN 分类模型。

* GNU Radio：构建实时信号处理流程。

* USRP B210：采集真实无线信号并验证模型。

### 六、一个值得进一步思考的问题

实际上，基于 CNN 的调制识别还有两条不同的技术路线：

路线 A：基于语谱图的 CNN

图像特征学习

I/Q 信号 → STFT → 语谱图 → CNN → 分类

路线 B：基于 I/Q 数据的 CNN

原始信号学习

I/Q 信号 → 一维 CNN → 特征提取 → 分类

两种方法各有优劣：

* 语谱图路线：能够利用时频结构，具有较强的可视化和解释便利性，但 STFT 会带来额外计算量，也可能损失部分相位信息。

* I/Q 路线：直接从原始复数基带数据中学习特征，避免显式时频变换，但对网络结构和训练数据有一定要求。

我的建议： 如果你想把它作为 AI + 通信方向的入门研究项目，可以先用 MATLAB 生成调制信号，分别实现两种 CNN，比较不同 SNR 下的识别准确率。

这样你不仅能掌握 CNN，还能进一步理解传统通信信号处理与深度学习之间的关系。
