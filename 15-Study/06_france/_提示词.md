# 法语笔记 · 卡片与补充提示词

> 适用目录：`15-Study/06_france/初级课程/`
> 目标：把课堂速记补成可复习的笔记，并生成 Flashcards v2 能同步到 Anki 的卡片。
> 原则：**Obsidian 是唯一源，Anki 只负责复习**；所有修改都在笔记里做。

## 0. 使用方式

| 场景 | 用哪一节 |
| --- | --- |
| 一篇笔记既要补全又要出卡 | 第 1 节「主提示词」 |
| 只补笔记，不出卡 | 第 2 节 |
| 只出卡，不改正文 | 第 3 节 |
| 一次处理整个 Unit | 第 4 节 |
| 检查已有卡片质量 | 第 5 节 |

用法：打开目标笔记 → 复制对应提示词 → 连同笔记内容一起发给 AI；或直接说“按 `_提示词.md` 处理当前笔记”。

处理完成后，在 Obsidian 命令面板运行 **Flashcards: Update Anki from current note**，再到 Anki 用 FSRS 复习。

## 1. 主提示词（补笔记 + 出卡）

```text
你是我的法语 A1 笔记整理与卡片制作助手。当前笔记是一篇法语初级课程笔记（Unit / Lesson 编号见文件名和正文）。

【任务】
先补全笔记，再出卡片。顺序不能反：卡片只能考补全后确认正确的内容。

【第一步：读全文】
1. 通读全文，按 Lesson 分节，列出每节实际出现的：词汇、动词变位、语法/句型、数字、国家/国籍。
2. 识别 Unit 和 Lesson 编号；文件名与正文冲突时，以正文为准，并在末尾说明。
3. 只处理本课出现的内容，不要混入其他课的知识。

【第二步：补笔记（不破坏原文）】
1. 保留原文全部内容、顺序、图片 ![[...]]、表格和高亮；不要重写全文。
2. 如果笔记没有 frontmatter，在开头补：
   ---
   课程: 法语
   章节: <Unit X / Lesson A-L>
   cards-deck: 法语::初级课程::<Unit X>
   tags:
     - 法语
   ---
   已有 frontmatter 则保留原字段，只补 cards-deck 和 tags。
3. 在原文末尾追加以下区块；没有的内容省略，不要硬凑：
   ## 📌 本课速查
   ### 词汇
   | 法语（带冠词） | 阴阳性/词性 | 中文 | 例句 |
   ### 动词变位
   | 动词 | je | tu | il/elle | nous | vous | ils/elles |
   ### 语法点
   - 规则一句话
   - 例外/易错
   - 2 个 A1 例句
   ## ⚠️ 易错点
   ## ✏️ 勘误
   | 原文 | 应为 | 说明 |
4. 每个名词必须带不定冠词并标阴阳性；每个动词给六个人称的现在时变位；例句 ≤10 词，必须是正确、完整的法语。
5. 原文错误（拼写、重音、变位、阴阳性、介词）不要直接删改：在原文对应处标 `（✏️ 应为：X）`，并在「勘误」表汇总。
6. 课文没出现但 A1 必须知道的补充内容，标 `（补充）`；不确定的不要写。
7. 本课没出现的时态、语式不要展开讲；不要写长篇语法讲义。

【第三步：出卡】
1. 按 Lesson 分节出卡，每节 3—8 张；整篇最多 25 张。宁少勿多。
2. 优先级：
   ① 动词现在时变位与词尾规律；
   ② 语法规则、例外、句型；
   ③ 高频词块（带冠词/阴阳性）；
   ④ 数字构成与易错数字；
   ⑤ 国家/国籍与介词 en / au / aux；
   ⑥ 原文里的易错点。
3. 只用以下四种语法：
   A. 单行问答：问题::答案
   B. 多行/表格/变位表：### 问题？ #card（答案写到下一个同级或更高级标题为止）
   C. 填空：==答案== 或 {1:答案}
   D. 复杂多行：flashcard 代码块（front / back / type，type 只用 basic、reversed、cloze、reminder）
   优先 A；变位表、规则对比用 B；词尾、介词、冠词用 C；D 少用。
4. 卡片红线：
   - 一张卡只考一个点；正面不能出现答案。
   - 名词答案必须带冠词和阴阳性；动词答案必须带人称。
   - 一个词多义时，正面加语境，如“（电脑）”“（书）”。
   - 不把一张变位表拆成 6 张卡；不考整句翻译；不考无规律的罕见拼写。
   - 发音卡只考原文明确标注的规则（如 -ent 不发音、h 不发音），不要自编 IPA。
   - 答案不超过 3 行；表格不超过 7 行。
5. 卡与卡之间空一行，统一放在文末 `## 卡片区`。

【第四步：输出】
1. 直接输出完整笔记 Markdown：原文 + 追加区块 + `## 卡片区`。
2. 不要输出解释、diff 或“以下是修改后的笔记”。
3. 最后一行写：本次补充 X 条、勘误 Y 条、新增卡 Z 张、待确认 N 条。
```

## 2. 只补笔记

```text
只补全当前法语笔记，不出卡片。

要求：
1. 保留原文全部内容、顺序、图片 ![[...]]、表格和高亮，不重写全文。
2. 在原文末尾追加：
   ## 📌 本课速查
   ### 词汇（法语带冠词 | 阴阳性/词性 | 中文 | 例句）
   ### 动词变位（六个人称的现在时）
   ### 语法点（规则 + 例外 + 2 个例句）
   ## ⚠️ 易错点
   ## ✏️ 勘误（原文 | 应为 | 说明）
3. 原文错误在对应处标 `（✏️ 应为：X）`，并在「勘误」表汇总；不要直接删改原文。
4. 补充内容标 `（补充）`；不确定的不要写；本课没出现的时态不要展开。
5. 每个名词带不定冠词和阴阳性；每个例句 ≤10 词，必须是正确、完整的法语。
6. 直接输出完整笔记，不要解释。最后一行写：本次补充 X 条、勘误 Y 条、待确认 N 条。
```

## 3. 只出卡

```text
只处理当前法语笔记的 `## 卡片区`，不要改正文和 frontmatter。

要求：
1. 已有 `## 卡片区` 就只重写卡片区；没有就在文末新增。
2. 按 Lesson 分节，每节 3—8 张，整篇最多 25 张。宁少勿多。
3. 优先做：动词变位、语法规则/例外、高频词块、数字、国家/国籍介词、原文易错点。
4. 只用语法的四种：A 单行问答 `问题::答案`；B `### 问题？ #card`；C 填空 `==...==` / `{1:...}`；D flashcard 代码块。
5. 一张卡只考一个点；正面不出现答案；名词带冠词和阴阳性；动词带人称；答案 ≤3 行。
6. 不把一张变位表拆成 6 张卡；不考整句翻译；不编造原文没有的知识。
7. 直接输出完整 `## 卡片区`，不要解释。最后一行写：新增 X 张、修改 Y 张、删除 Z 张、待补充 N 条。
```

## 4. 批量处理

```text
按文件名顺序处理当前文件夹下的法语笔记（排除 `_提示词.md`）。
每次只处理一篇：输出该篇完整笔记（原文 + 补充区块 + 卡片区），然后停下，等我确认后再处理下一篇。
不要合并多篇，不要总结其他篇。
如果某篇没有可出卡的内容，保留原文，并在末尾写：
## 卡片区
（本篇暂无可出卡内容：原因……）
```

## 5. 卡片质检

```text
你是法语卡片质检员。只检查当前笔记 `## 卡片区` 里的每一张卡。

检查项：
1. 是否一卡一点？正面是否泄漏答案？
2. 名词是否带冠词和阴阳性？动词是否带人称？
3. 答案是否超过 3 行？是否在复述整段课文？
4. 语法是否正确（:: / #card / ==...== / {1:...} / flashcard）？标题卡的答案边界是否正确？
5. 是否把一张变位表拆成了 6 张卡？是否考了无规律的罕见拼写？
6. 是否有编造原文没有的法语搭配或 IPA？
7. 是否漏了本课的核心变位、语法规则或易错点？

输出：
- 先输出「问题清单」：卡号/卡面 + 问题 + 建议（合并/拆分/删除/改语法）。
- 再输出修正后的完整 `## 卡片区`。
- 不要改正文和 frontmatter。
```

## 6. 法语卡片示例

### 例 1：动词变位（B 语法，整张表一张卡）

```markdown
### parler 的现在时六个人称变位？ #card

| 人称 | 变位 |
| --- | --- |
| je | parle |
| tu | parles |
| il/elle | parle |
| nous | parlons |
| vous | parlez |
| ils/elles | parlent |

⚠ 易错：`-ent` 不发音；`nous` 的词尾是 `-ons`。
```

### 例 2：词尾填空（C 语法）

```markdown
finir 现在时：je finis, tu finis, il/elle finit, nous {1:finissons}, vous {2:finissez}, ils/elles {3:finissent}。
```

### 例 3：语法规则（B 语法）

```markdown
### Il faut 的两种接法？ #card

① `Il faut + 动词原形`：Il faut respecter les règles.
② `Il faut + 名词`：Il faut une carte d'identité.

⚠ 易错：否定是 `Il ne faut pas + 动词原形`。
```

### 例 4：易错点（A 语法）

```markdown
“我 20 岁”用法语怎么说？::J'ai 20 ans。⚠ 易错：年龄用 avoir，不用 être。
```

### 例 5：词汇（A 语法，答案带冠词和阴阳性）

```markdown
“电脑”的法语（带冠词）？::un ordinateur（阳性）。例：J'achète un ordinateur.
```

### 例 6：国家与介词（A 语法）

```markdown
“去法国”用法语怎么说？::aller en France。⚠ 易错：阴性国家用 en，阳性国家用 au，复数国家用 aux。
```

### 例 7：复数例外（B 语法）

```markdown
### -ou 结尾名词哪些复数加 x？ #card

bijou、caillou、chou、genou、hibou、joujou、pou → 加 `-x`；其余 `-ou` 加 `-s`。

⚠ 易错：这七个是常考例外，不要漏。
```

### 例 8：数字（A 语法）

```markdown
70 的法语？::soixante-dix。⚠ 易错：70–79 用 60+10 构成；77 = soixante-dix-sept，不是 soixante-sept。
```

## 7. 笔记补充输出模板

补完后，笔记末尾大致长这样（按本课实际内容删减）：

```markdown
## 📌 本课速查

### 词汇
| 法语（带冠词） | 阴阳性/词性 | 中文 | 例句 |
| --- | --- | --- | --- |
| un ordinateur | 阳性名词 | 电脑 | J'achète un ordinateur. |
| une famille | 阴性名词 | 家庭 | Voici ma famille. |

### 动词变位
| 动词 | je | tu | il/elle | nous | vous | ils/elles |
| --- | --- | --- | --- | --- | --- | --- |
| parler | parle | parles | parle | parlons | parlez | parlent |

### 语法点
- **-er 动词现在时**：词干 + `-e, -es, -e, -ons, -ez, -ent`。
- 例外/易错：`-ent` 不发音；`nous` 词尾是 `-ons`，不是 `-ons` 之外的拼法。
- 例：Je parle français. / Nous parlons français.

## ⚠️ 易错点
- 年龄用 `avoir`：J'ai 20 ans，不说 Je suis 20 ans。
- 阴性国家用 `en`：aller en France；阳性国家用 `au`：aller au Canada。

## ✏️ 勘误
| 原文 | 应为 | 说明 |
| --- | --- | --- |
| II faut | Il faut | `II` 是字母 I，不是 `Il` |
| les regles | les règles | 缺少重音 |
```

## 8. 当前三篇笔记的优先核查点

> 以下只是初步清单，处理时仍以教材/词典为准；不要照抄，先核对原文。

### `unit2.md`（Lessons I–Q）

- `II` / `IIs` → `Il` / `Ils`（常见的字母 I 误打）。
- `ving-neuf` → `vingt-neuf`；`quarante te un` → `quarante et un`。
- `a` 作介词时 → `à`：`De 20 a 50` → `De 20 à 50`。
- `la famile` → `la famille`；`situaition` → `situation`；`celibataire` → `célibataire`。
- `grand-pere` / `grand-mere` / `pere` / `mere` / `beau-frere` / `belle-soeur` 补重音：`grand-père`、`grand-mère`、`père`、`mère`、`beau-frère`、`belle-sœur`。
- `Le beau-frere brother`：`beau-frère` 是**姻亲**（姐夫/妹夫/大伯子等），不是普通的“brother”；`belle-sœur` 同理。
- `Que est votre no,?` → `Quel est votre nom ?`
- `FINIR finishi` → `finir (to finish)`；`FNIR` → `FINIR`。
- `unir` 的变位表只写了前两个人称，补 `il/elle unit`、`nous unissons`、`vous unissez`、`ils/elles unissent`。
- `Aller(to go)` 只给了不定式，补现在时变位：`je vais, tu vas, il/elle va, nous allons, vous allez, ils/elles vont`。
- `à la television` → `à la télévision`。

### `Unit3.md`（Lessons A–L）

- 复数：`des livre` → `des livres`；`des eau` → `des eaux`；`des tuyau` → `des tuyaux`；`des feu` → `des feux`；`des bijou` → `des bijoux`；`des caillou` → `des cailloux`；`des chou` → `des choux`；`des genou` → `des genoux`；`des hibou` → `des hiboux`；`des joujou` → `des joujoux`；`des pou` → `des poux`。
- `un boeuf` / `un oeuf` / `un oeil` 写成 `un bœuf` / `un œuf` / `un œil`；复数 `des bœufs` / `des œufs` / `des yeux`。
- `Dovoir` → `Devoir`；`Je doi==s==` 等拼写保留，但注意 `Ils/Elles doivent`。
- 国家名补大小写和重音：`La Grèce`、`Le Luxembourg`、`L'Italie`、`Le Royaume-Uni`、`La Suède`、`La Lituanie`、`La Pologne`、`La République tchèque`、`La Slovénie`。
- 国籍：`canadian` → `canadien`；`argenntine` → `argentine`；`chiliennne` → `chilienne`；`La bolivie` → `La Bolivie`。
- `Nous attendons tranquilement` → `tranquillement`；`votre re(2)ponse` → `votre réponse`。
- `Je vous écrit` → `Je vous écris`（écrire 的 je 变位是 `écris`）。
- `Cet aprè-mide` / `Demain après-mide` → `Cet après-midi` / `Demain après-midi`。
- 数字：`77 soixante-sept` → `soixante-dix-sept`；`82 quatre-vingt-trois` → `quatre-vingt-deux`；`81 quatre-vingt -un` → `quatre-vingt-un`；`92 quatre- vingt-douze` → `quatre-vingt-douze`。补全 83–89、93–100。

### `Unit 4 -Lesson G.md`

- `FALLOIR` → `falloir`（不定式）；实际句型是 `Il faut`。
- `II faut` → `Il faut`。
- `les regles` → `les règles`；`carte d'identite` → `carte d'identité`。
- 可补：`Il faut + 动词原形` / `Il faut + 名词` 两种接法，以及否定 `Il ne faut pas + 动词原形`。

### 个人速记对照

| 速记 | 含义 |
| --- | --- |
| `e(2)` | `é`（如 `re(2)pondre` → `répondre`） |
| `e(4)` | `è`（如 `Sue(4)de` → `Suède`） |
| `II` | `Il`（字母 I 误打） |
| `==...==` | 原文重点/发音提示，补笔记时保留 |
