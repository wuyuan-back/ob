## 📖 一、家庭成员

| 法语 | 中文 | 备注 |
| --- | --- | --- |
| le père | 父亲 | |
| la mère | 母亲 | |
| les parents | 父母 | 永远是复数 |
| le frère | 兄弟 | |
| la sœur | 姐妹 | |
| le fils | 儿子 | 词尾 s 不发音：[fis] |
| la fille | 女儿；女孩 | 两个意思靠上下文 |
| l'enfant | 孩子 | 阴阳同形，复数 les enfants |
| le grand-père / la grand-mère | 祖父 / 祖母 | |
| les grands-parents | 祖父母 | |
| l'oncle / la tante | 叔伯舅 / 姑姨 | |
| le cousin / la cousine | 堂表兄弟 / 堂表姐妹 | |
| le mari / la femme | 丈夫 / 妻子 | `femme` 也指"女人" |
| le petit-fils / la petite-fille | 孙子 / 孙女 | |

> **记词规则不变**：记 `le père`，不要只记 `père`。阴阳性错了，后面冠词、形容词全错。

### 三个易混

- `la fille` = 女儿 / 女孩；`la femme` = 妻子 / 女人。说"我妻子"用 `ma femme`，不用 `ma fille`。
- `les parents` 在法语里通常指**父母**，不是"亲戚"（亲戚是 `la famille` / `les proches`）。
- `l'enfant` 阴阳同形，但形容词仍要配合：`un petit enfant` / `une petite enfant`。

## 📖 二、主有形容词（本周重点）

表示"我的 / 你的 / 他的"，**形式由后面名词的性和数决定，不由所有者决定**。

| 所有者 | 阳性单数 | 阴性单数 | 复数 |
| --- | --- | --- | --- |
| je | mon | ma | mes |
| tu | ton | ta | tes |
| il / elle | son | sa | ses |
| nous | notre | notre | nos |
| vous | votre | votre | vos |
| ils / elles | leur | leur | leurs |

### 三条要点

**① 跟名词，不跟人。**

`sa mère` 既可以是"他的妈妈"，也可以是"她的妈妈"——因为 `mère` 是阴性，所以用 `sa`。想知道是谁的妈妈，只能靠上下文。

**② 阴性名词以元音或哑音 h 开头，用 mon / ton / son。**

为了不发两个元音相撞：

- `mon amie`（不是 `ma amie`）我的（女）朋友
- `ton école` 你的学校
- `son idée` 他/她的主意
- `mon histoire` 我的故事

**③ notre / votre / leur 阴阳同形，只分单复数。**

- `notre père` / `notre mère` / `nos parents`
- `leur enfant`（一个孩子）/ `leurs enfants`（几个孩子）

> ⚠️ `leur` 和 `leurs` 只差一个 s，但意思差"一个"和"几个"，考试常考。

## 📖 三、形容词的性数配合

形容词必须跟着名词变**性**（阴/阳）和**数**（单/复）。

### 规则变化

| 情况 | 变化 | 例 |
| --- | --- | --- |
| 一般 | 加 -e | grand → grand**e** |
| 已以 -e 结尾 | 不变 | timide → timide |
| -eux | → -euse | heureux → heureu**se** |
| -f | → -ve | actif → acti**ve** |
| -er | → -ère | premier → premi**ère** |
| -ien | → -ienne | italien → italien**ne** |
| -on | → -onne | bon → bon**ne** |

### 八个不规则（必背）

| 阳性 | 阴性 | 中文 |
| --- | --- | --- |
| beau | belle | 漂亮 |
| vieux | vieille | 老 |
| nouveau | nouvelle | 新 |
| blanc | blanche | 白 |
| long | longue | 长 |
| gros | grosse | 胖 / 粗 |
| gentil | gentille | 友善 |
| faux | fausse | 假 |

### 复数

- 一般加 `-s`：`grands` / `grandes`
- 已以 `-s` / `-x` 结尾不变：`heureux` → `heureux`
- `-eau` → `-eaux`：`beau` → `beaux`
- `-al` → `-aux`：`génial` → `géniaux`

### 元音前的三个特殊阳性形式

| 一般阳性 | 元音/哑音 h 前 | 例 |
| --- | --- | --- |
| beau | **bel** | un bel homme |
| vieux | **vieil** | un vieil ami |
| nouveau | **nouvel** | un nouvel appartement |

> 只影响**阳性单数**，阴性不受影响：`une belle femme`、`une vieille amie`。

## 📖 四、形容词放前面还是后面

**默认放名词后面**，只有一小批高频短形容词放前面。

| 位置 | 类型 | 例 |
| --- | --- | --- |
| **后** | 颜色、国籍、形状、分词 | une voiture **rouge**、une étudiante **chinoise**、une porte **ouverte** |
| **前** | 美丑、年龄、好坏、大小 | un **petit** chat、une **belle** ville、un **bon** repas、un **jeune** homme |

记法：**BAGS** —— Beauty（美）、Age（年龄）、Goodness（好坏）、Size（大小）。

### 位置改变意思（知道就行，A2 再练）

| 前置 | 后置 |
| --- | --- |
| un **grand** homme 伟人 | un homme **grand** 高个子男人 |
| une **ancienne** école 以前的学校 | une école **ancienne** 古老的学校 |
| mon **propre** livre 我自己的书 | un livre **propre** 干净的书 |

## 📖 五、数字 70–100

20–69 是规则的，`[[unit2]]` 已学。**70 以后是法国特色的加法/乘法**：

| 数字 | 写法 | 拆开看 |
| --- | --- | --- |
| 70 | soixante-dix | 60 + 10 |
| 71 | soixante et onze | 60 + 11（有 et） |
| 72 | soixante-douze | 60 + 12 |
| 80 | quatre-vingts | 4 × 20（**有 s**） |
| 81 | quatre-vingt-un | 4×20 + 1（**无 s，无 et**） |
| 90 | quatre-vingt-dix | 4×20 + 10 |
| 91 | quatre-vingt-onze | 4×20 + 11 |
| 99 | quatre-vingt-dix-neuf | 4×20 + 19 |
| 100 | cent | |
| 101 | cent un | |
| 200 | deux cents | 结尾**有 s** |
| 201 | deux cent un | 后面还有数字，**无 s** |

### 三条规则

1. **`et` 只出现在 21、31、41、51、61、71**。81 和 91 **不加** `et`。
2. **`quatre-vingts` 和 `cents` 的 s**：后面不接别的数字才写 s。`quatre-vingts` ✅ / `quatre-vingt-un` ✅
3. 比利时和瑞士说 `septante`（70）、`nonante`（90），但教材和考试用法国说法。

## 📖 六、介绍家庭的五个句型

| 句型 | 例 | 注意 |
| --- | --- | --- |
| J'ai + 数字 + 家庭成员 | J'ai un frère et deux sœurs. | 有兄弟姐妹用 avoir |
| Nous sommes + 数字 | Nous sommes quatre à la maison. | 说"家里几口人" |
| Mon/Ma + 成员 + est + 职业 | Mon père est professeur. | 职业前不加冠词 |
| Il/Elle a + 年龄 + ans | Ma mère a cinquante ans. | 年龄用 avoir |
| Mes parents habitent à + 城市 | Mes parents habitent à Lyon. | habiter à |

**独生子女**：`Je suis fils unique.` / `Je suis fille unique.`（不加冠词）

## 📌 本周速查

### 词汇

| 法语 | 词性 | 中文 |
| --- | --- | --- |
| le père / la mère | 名词 | 父亲 / 母亲 |
| le frère / la sœur | 名词 | 兄弟 / 姐妹 |
| le fils / la fille | 名词 | 儿子 / 女儿 |
| l'enfant | 名词（阴阳同形） | 孩子 |
| les grands-parents | 名词复数 | 祖父母 |
| le cousin / la cousine | 名词 | 堂表兄弟 / 姐妹 |
| le mari / la femme | 名词 | 丈夫 / 妻子 |
| unique | 形容词 | 唯一的 |
| aîné / cadet | 形容词 | 年长的 / 年幼的 |

### 语法点

- **主有形容词跟名词的性数**，不跟所有者：`sa mère` 可能是"他的"也可能是"她的"。
- **阴性名词元音开头用 mon/ton/son**：`mon amie`、`son école`。
- **形容词默认后置**；BAGS（美、年龄、好坏、大小）前置。
- **元音前阳性特殊形式**：bel / vieil / nouvel。
- **71 有 et，81 没有**；`quatre-vingts` 后不接数字才带 s。
- **职业前不加冠词**：`Il est professeur.`

---

## ⚠️ 易错点

- `ma amie` ❌ → `mon amie` ✅（元音开头）
- `mes père` ❌ → `mon père` ✅（一个父亲用单数）
- `leur enfants` ❌ → `leurs enfants` ✅（复数名词）
- `une petit maison` ❌ → `une petite maison` ✅
- `un beau homme` ❌ → `un bel homme` ✅
- `quatre-vingt et un` ❌ → `quatre-vingt-un` ✅（81 不加 et）
- `deux cent un` 写 `deux cents un` ❌（后面有数字就不加 s）
- `Je suis un étudiant` 不自然 → `Je suis étudiant` ✅
- `Mon père il est professeur` ❌ 主语重复 → `Mon père est professeur` ✅
