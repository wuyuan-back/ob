## 📖 一、问时间和读时间

### 问

| 说法 | 正式度 |
| --- | --- |
| Quelle heure est-il ? | 标准 |
| Il est quelle heure ? | 口语 |
| Vous avez l'heure ? | 最口语，问陌生人 |

### 答：`Il est + 数字 + heure(s)`

| 时间 | 法语 | 注意 |
| --- | --- | --- |
| 1:00 | Il est **une** heure. | ⚠️ 用 une，不是 un |
| 2:00 | Il est deux heures. | 复数加 s |
| 2:05 | Il est deux heures cinq. | 直接加分钟 |
| 2:10 | Il est deux heures dix. | |
| 2:15 | Il est deux heures **et quart**. | 一刻钟 |
| 2:30 | Il est deux heures **et demie**. | 半 |
| 2:45 | Il est trois heures **moins le quart**. | 差一刻三点 |
| 2:50 | Il est trois heures **moins dix**. | 差十分三点 |
| 12:00 | Il est **midi**. | 正午 |
| 0:00 | Il est **minuit**. | 午夜 |

### 三个要点

1. **45 分以后用"下一个整点 + moins"**，不是"两点四十五"。
2. **`midi` 和 `minuit` 不接 heure**：`Il est midi.` ✅　`Il est douze heures.` 只在 24 小时制里说。
3. **一天三段**：`du matin`（0–12）、`de l'après-midi`（12–18）、`du soir`（18–24）。
   `Il est huit heures du soir.` = 晚上八点。

### 24 小时制（车站、机场、正式场合）

`Le train part à quatorze heures trente.`（14:30）
`Le magasin ouvre à neuf heures.`

> 口语用 12 小时制 + du matin/du soir；时刻表用 24 小时制。

### 问"几点做某事"

`À quelle heure… ?`

- `À quelle heure tu te lèves ?` 你几点起床？
- `À huit heures.` 八点。

## 📖 二、星期、月份、日期

### 星期（**不大写**）

lundi · mardi · mercredi · jeudi · vendredi · samedi · dimanche

| 说法 | 意思 |
| --- | --- |
| **lundi** | 这个周一 / 下周一（具体某天） |
| **le lundi** | 每周一（习惯性） |
| **tous les lundis** | 每个周一（强调） |

> `Je travaille lundi.` = 我这个周一上班。
> `Je travaille le lundi.` = 我每周一上班。

### 月份（**不大写**）

janvier · février · mars · avril · mai · juin · juillet · août · septembre · octobre · novembre · décembre

### 日期

- 每月 1 号：`le premier`（写作 `le 1er`）
- 其他：`le deux`、`le trois`……**用基数词，不用序数词**
- `le 29 octobre` 10 月 29 日

### 说"今天几号"

| 说法 | 正式度 |
| --- | --- |
| Nous sommes le 29 octobre. | 标准 |
| On est le 29 octobre. | 口语 |
| C'est le 29 octobre. | 口语 |

### 年份和季节

- 年份：`en 2026`（不加冠词）
- 季节：`au printemps`（唯一用 au）、`en été`、`en automne`、`en hiver`

## 📖 三、频率副词和时间副词

| 频率 | 法语 | 位置 |
| --- | --- | --- |
| 100% | toujours 总是 | 动词后 |
| 80% | souvent 经常 | 动词后 |
| 50% | parfois / quelquefois 有时 | 动词后 |
| 20% | rarement 很少 | 动词后 |
| 0% | jamais 从不 | 动词后（需 ne） |

**位置规则：放在变位动词后面。**

- `Je vais **souvent** au cinéma.` 我经常去电影院。
- `Il est **toujours** en retard.` 他总是迟到。
- `Je ne fume **jamais**.` 我从不抽烟。

**复合过去时里放中间**（助动词和过去分词之间）：

- `J'ai **souvent** entendu cette chanson.` 我经常听到这首歌。

### 其他时间副词

aujourd'hui 今天 · hier 昨天 · demain 明天 · avant-hier 前天 · après-demain 后天 · maintenant 现在 · ce matin 今天早上 · ce soir 今晚 · cette semaine 这周

## 📖 四、代词 `on`

`on` 是法语口语里最常用的"我们"，**动词永远用第三人称单数**。

| 书面 / 正式 | 口语 |
| --- | --- |
| Nous allons au cinéma. | **On va** au cinéma. |
| Nous mangeons à midi. | **On mange** à midi. |
| Nous sommes quatre. | **On est** quatre. |

`on` 还有两个意思：

- **人们 / 大家**：`On parle français ici.` 这里说法语。
- **某人（不确定）**：`On m'a appelé.` 有人给我打电话了。

> ⚠️ `on` 后面动词**绝不加 -ons**：`On allons` ❌ → `On va` ✅

## 📖 五、`faire` 与日常动词

### faire 变位（不规则，必背）

| 人称 | 变位 | 读音 |
| --- | --- | --- |
| je | fais | [fɛ] |
| tu | fais | [fɛ] |
| il / elle / on | fait | [fɛ] |
| nous | faisons | [fəzɔ̃] |
| vous | **faites** | [fɛt] |
| ils / elles | font | [fɔ̃] |

> 两个坑：`vous faites` 不是 `vous faisez`；`nous faisons` 读 [fəzɔ̃]，不读 [fɛzɔ̃]。

### 六个固定搭配

| 搭配 | 意思 |
| --- | --- |
| faire du sport | 做运动 |
| faire les courses | 采购（日常买菜） |
| faire la cuisine | 做饭 |
| faire le ménage | 打扫 |
| faire ses devoirs | 做作业 |
| faire un voyage | 旅行 |

> `faire` + **部分冠词**（du/de la）表示"做某类活动"，第 4 周细讲。

### 日常作息动词

| 动词 | 变位（je） | 意思 |
| --- | --- | --- |
| se lever | je me lève | 起床 |
| se coucher | je me couche | 上床睡觉 |
| se laver | je me lave | 洗漱 |
| s'habiller | je m'habille | 穿衣服 |
| prendre | je prends | 吃 / 拿 / 乘 |
| partir | je pars | 出发 |
| rentrer | je rentre | 回家 |
| dormir | je dors | 睡觉 |

> 这些是**代词式动词**（se lever 等），反身代词跟人称变：`je me lève / tu te lèves / il se lève / nous nous levons / vous vous levez / ils se lèvent`。第 9 周讲它们的过去时。

## 📖 六、范文：我的一天

> Le matin, je me lève à sept heures. Je prends le petit-déjeuner à sept heures et demie. Je vais à l'université à huit heures. Je déjeune à midi avec mes amis. L'après-midi, j'étudie à la bibliothèque. Le soir, je rentre à six heures et je fais mes devoirs. Je me couche à onze heures.

拆开看结构：

| 时间词 | 动作 |
| --- | --- |
| Le matin | je me lève à sept heures |
| à sept heures et demie | je prends le petit-déjeuner |
| à midi | je déjeune |
| L'après-midi | j'étudie |
| Le soir | je rentre / je fais mes devoirs |
| à onze heures | je me couche |

> **时间词放句首**是法语叙事最自然的写法，比全塞在句尾清楚得多。

## 📌 本周速查

### 词汇

| 法语 | 词性 | 中文 |
| --- | --- | --- |
| une heure | 名词 | 小时；点钟 |
| un quart | 名词 | 一刻钟 |
| une demi-heure | 名词 | 半小时 |
| midi / minuit | 名词 | 正午 / 午夜 |
| le matin / l'après-midi / le soir | 名词 | 早上 / 下午 / 晚上 |
| toujours / souvent / parfois / rarement / jamais | 副词 | 频率副词 |
| se lever / se coucher | 代词式动词 | 起床 / 睡觉 |
| faire les courses | 短语 | 采购 |
| le ménage | 名词 | 家务 |

### 语法点

- **问时间**：`Quelle heure est-il ?`；答 `Il est + 数字 + heure(s)`。
- **1 点用 une heure**；**12 点用 midi**，0 点用 `minuit`。
- **45 分后用"下个整点 + moins"**：`trois heures moins le quart`。
- **星期、月份不大写**；`le lundi` = 每周一。
- **频率副词放变位动词后**；复合过去时放助动词和分词之间。
- **`on` + 第三人称单数动词**，口语代替 nous。
- **`faire`**：fais / fais / fait / faisons / **faites** / font。

## ⚠️ 易错点

- `Il est un heure` ❌ → `Il est une heure` ✅
- `Il est douze heures`（想说正午）→ `Il est midi` ✅
- `On allons` ❌ → `On va` ✅
- `Vous faisez` ❌ → `Vous faites` ✅
- `Nous faiseons` ❌ → 读音 [fəzɔ̃]，写法 `faisons` ✅
- `Je vais au cinéma souvent` 语序可以但生硬 → `Je vais souvent au cinéma` 更自然
- `le Lundi` ❌ → `le lundi` ✅（星期不大写）
- `en printemps` ❌ → `au printemps` ✅（唯一用 au 的季节）
- `Je me lève` 漏反身代词 → `Je me lève` ✅（中文没有这个概念，最容易漏）
