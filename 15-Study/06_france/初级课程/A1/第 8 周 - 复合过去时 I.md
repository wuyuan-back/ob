## 📖 一、复合过去时是什么

**结构：`助动词（avoir 或 être）的现在时 + 过去分词`**

| 人称 | avoir | + parlé |
| --- | --- | --- |
| je | ai | **j'ai parlé** |
| tu | as | **tu as parlé** |
| il / elle / on | a | **il a parlé** |
| nous | avons | **nous avons parlé** |
| vous | avez | **vous avez parlé** |
| ils / elles | ont | **ils ont parlé** |

> 两个词缺一不可：`J'ai parlé` ✅　`J'ai parle` ❌（分词要变）　`Je parlé` ❌（缺助动词）

### 它对应中文的什么

| 法语 | 中文 |
| --- | --- |
| J'ai mangé. | 我吃了 / 我吃过了。 |
| Il a travaillé hier. | 他昨天工作了。 |
| Nous avons fini. | 我们做完了。 |

**注意**：法语复合过去时同时覆盖中文的"了"和"过"，具体靠时间词区分。

---

## 📖 二、过去分词怎么变

### 三类规则动词

| 类型 | 规则 | 例 |
| --- | --- | --- |
| **-er** | → **-é** | parler → parl**é**；manger → mang**é**；étudier → étudi**é** |
| **-ir** | → **-i** | finir → fin**i**；choisir → chois**i**；réussir → réuss**i** |
| **-re** | → **-u** | attendre → attend**u**；répondre → répond**u**；vendre → vend**u** |

> `-er` 动词占法语动词的 90%，所以 **-é** 是最常见的过去分词词尾。

### 十个高频不规则（必背）

| 不定式 | 过去分词 | 中文 |
| --- | --- | --- |
| avoir | **eu** | 有 |
| être | **été** | 是 |
| faire | **fait** | 做 |
| prendre | **pris** | 拿 / 乘 / 吃 |
| mettre | **mis** | 放 |
| voir | **vu** | 看见 |
| boire | **bu** | 喝 |
| lire | **lu** | 读 |
| écrire | **écrit** | 写 |
| dire | **dit** | 说 |

**例句**：

- `J'ai fait mes devoirs.` 我做了作业。
- `Il a pris le métro.` 他乘了地铁。
- `Nous avons vu un film.` 我们看了一部电影。
- `Elle a écrit une lettre.` 她写了一封信。

## 📖 三、否定和疑问

### 否定：`ne + 助动词 + pas + 过去分词`

| 肯定 | 否定 |
| --- | --- |
| J'ai parlé. | Je **n'ai pas** parlé. |
| Il a mangé. | Il **n'a pas** mangé. |
| Nous avons fini. | Nous **n'avons pas** fini. |

> ⚠️ `pas` 放在**助动词后面**，不是分词后面。`Je n'ai parlé pas` ❌

### 疑问：三种方式

| 方式 | 例 |
| --- | --- |
| 语调 | Tu as parlé ? |
| est-ce que | Est-ce que tu as parlé ? |
| 倒装 | As-tu parlé ? |

倒装时是**助动词和主语**倒装，分词不动：`A-t-il parlé ?`（加 -t-，第 5 天的规则）

### 其他否定词同理

- `Je n'ai **jamais** vu ce film.` 我从没看过这部电影。
- `Il n'a **rien** dit.` 他什么都没说。
- `Nous n'avons **pas encore** fini.` 我们还没做完。

## 📖 四、时间标记

复合过去时几乎总和一个时间词一起出现：

| 法语 | 中文 |
| --- | --- |
| hier | 昨天 |
| avant-hier | 前天 |
| la semaine dernière | 上周 |
| le mois dernier | 上个月 |
| l'année dernière | 去年 |
| il y a deux jours | 两天前 |
| ce matin | 今天早上 |
| déjà | 已经 |
| pas encore | 还没 |
| jamais | 从未 |

**例句**：

> Hier, j'ai travaillé toute la journée. Le soir, j'ai dîné avec des amis. Nous avons parlé pendant deux heures. Je suis rentré à minuit.

---

## 📖 五、读音陷阱：`-é` 和 `-er` 同音

`parlé`（过去分词）和 `parler`（不定式）**读音完全一样**，都是 [paʁle]。

区分只能靠前面的词：

| 写法 | 意思 | 靠什么区分 |
| --- | --- | --- |
| J'**ai** parlé. | 我说了（过去） | 助动词 ai |
| Je **vais** parler. | 我要说（将来） | 助动词 vais |
| Je **veux** parler. | 我想说 | 半助动词 veux |
| **Parler** est facile. | 说很容易 | 句首无主语 |

> 听力上必须先抓住助动词。**这是 A1 听力最容易漏的一环。**

---

## 📖 六、什么时候用 avoir（先记住这条）

**绝大多数动词用 avoir**，包括所有能带宾语的动词。

| 用 avoir | 例 |
| --- | --- |
| 及物动词（有宾语） | manger, boire, lire, écrire, voir, faire, prendre |
| 大部分不及物动词 | travailler, dormir, répondre, téléphoner |

**例外（用 être）只有两类**，下周讲：

1. 16 个表示"移动 / 状态变化"的动词（aller, venir, arriver, partir…）
2. 所有代词式动词（se lever, se coucher…）

> 今天先建立默认值：**不确定就用 avoir**，等下周学了 être 那 16 个再细化。

## 📌 本周速查

### 词汇

| 法语 | 词性 | 中文 |
| --- | --- | --- |
| hier | 副词 | 昨天 |
| avant-hier | 副词 | 前天 |
| la semaine dernière | 短语 | 上周 |
| déjà | 副词 | 已经 |
| pas encore | 短语 | 还没 |
| un film | 名词（阳） | 电影 |
| une lettre | 名词（阴） | 信 |

### 语法点

- **公式**：`avoir 现在时 + 过去分词`。
- **分词**：-er → -é；-ir → -i；-re → -u。
- **不规则**：eu, été, fait, pris, mis, vu, bu, lu, écrit, dit。
- **否定**：`ne + 助动词 + pas + 分词`。
- **倒装**：`As-tu parlé ?` / `A-t-il parlé ?`
- **默认用 avoir**，être 只给 16 个移动动词和代词式动词。

---

## ⚠️ 易错点

- `Je parlé` ❌ → `J'ai parlé` ✅（漏助动词）
- `J'ai parle` ❌ → `J'ai parlé` ✅（分词没变）
- `Je n'ai parlé pas` ❌ → `Je n'ai pas parlé` ✅
- `J'ai allé` ❌ → `Je suis allé` ✅（aller 用 être，下周讲）
- `J'ai fini` vs `Je finis` 混——前者是过去，后者是现在
- 听力上把 `j'ai parlé` 听成 `je vais parler`——注意助动词
- `Hier, je mange` ❌ 有过去时间词就要用过去时（除非叙述习惯）
- `J'ai vu un film` 后面又加 `hier` 位置随意，但**放句首最自然**：`Hier, j'ai vu un film.`
