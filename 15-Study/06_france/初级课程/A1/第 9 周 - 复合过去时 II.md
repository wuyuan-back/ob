## 📖 一、16 个用 être 的动词

记法：**DR MRS VANDERTRAMP**（每个字母对应一个动词）

| 字母 | 动词 | 过去分词 | 中文 |
| --- | --- | --- | --- |
| **D** | devenir | devenu | 变成 |
| **R** | revenir | revenu | 回来 |
| **M** | monter | monté | 上去 |
| **R** | rester | resté | 留下 |
| **S** | sortir | sorti | 出去 |
| **V** | venir | venu | 来 |
| **A** | aller | allé | 去 |
| **N** | naître | né | 出生 |
| **D** | descendre | descendu | 下去 |
| **E** | entrer | entré | 进入 |
| **R** | retourner | retourné | 返回 |
| **T** | tomber | tombé | 跌倒 |
| **R** | rentrer | rentré | 回家 |
| **A** | arriver | arrivé | 到达 |
| **M** | mourir | mort | 死亡 |
| **P** | partir | parti | 出发 |

> 共同点：**全是"移动"或"状态变化"**——从一个地方到另一个地方，从生到死。这个语义线索比死记首字母更可靠。

### 两个特殊形式

- `naître → né`（不是 naîtu）
- `mourir → mort`（不是 mouri）

## 📖 二、过去分词要和主语配合

用 **être** 时，过去分词相当于形容词，**必须跟主语同性同数**：

| 主语 | aller | 写法 |
| --- | --- | --- |
| il | est | all**é** |
| elle | est | all**ée** |
| ils | sont | all**és** |
| elles | sont | all**ées** |
| nous | sommes | all**és**（有男有女也算阳复） |
| vous | êtes | all**é / allée / allés / allées**（看实际对象） |

**例句**：

- `Elle est arrivée à huit heures.` 她八点到的。
- `Ils sont partis hier.` 他们昨天走了。
- `Elles sont restées à la maison.` 她们留在家里了。
- `Nous sommes allés au cinéma.` 我们去了电影院。

> ⚠️ 对比上周：**avoir 助动词时，分词不配合主语**。
> `Elle a mangé.` ✅（不是 mangée）　`Elle est allée.` ✅（要加 e）

## 📖 三、代词式动词的过去时

结构：**`se 的变位 + être + 过去分词`**，分词同样配合主语。

### se lever（起床）

| 人称 | 变位 |
| --- | --- |
| je | me suis levé(e) |
| tu | t'es levé(e) |
| il | s'est levé |
| elle | s'est levée |
| nous | nous sommes levés |
| vous | vous êtes levé(e)(s) |
| ils | se sont levés |
| elles | se sont levées |

### 其他常用代词式动词

| 动词 | 过去时（je） | 中文 |
| --- | --- | --- |
| se réveiller | me suis réveillé(e) | 醒来 |
| se laver | me suis lavé(e) | 洗漱 |
| s'habiller | me suis habillé(e) | 穿衣 |
| se coucher | me suis couché(e) | 上床 |
| s'amuser | me suis amusé(e) | 玩得开心 |
| se dépêcher | me suis dépêché(e) | 赶紧 |

### 否定和疑问

- 否定：`Je **ne me suis pas** levé.`（ne 在反身代词前）
- 疑问：`Est-ce que tu **t'es** levé ?` / `**T'es**-tu levé ?`

> ⚠️ 顺序不能乱：**ne + 反身代词 + 助动词 + pas + 分词**。

## 📖 四、同一个动词，avoir 还是 être

`monter`、`descendre`、`sortir`、`rentrer`、`passer` 这几个**两副面孔**：

| 用法 | 助动词 | 例 |
| --- | --- | --- |
| 单独表移动（不及物） | **être** | Je **suis monté** au premier étage. 我上了二楼。 |
| 带直接宾语（及物） | **avoir** | J'**ai monté** les valises. 我把箱子搬上去了。 |
| 单独表移动 | **être** | Elle **est sortie**. 她出去了。 |
| 带直接宾语 | **avoir** | J'**ai sorti** les poubelles. 我把垃圾拿出去了。 |

**判断法**：后面有没有直接宾语。**有宾语 → avoir；没宾语 → être。**

> `passer` 更特殊：`J'ai passé un examen`（avoir，参加考试）、`Je suis passé par Paris`（être，经过）。A1 阶段只记 `passer un examen` 用 avoir。

---

## 📖 五、两种助动词对比总结

| | avoir 组 | être 组 |
| --- | --- | --- |
| 覆盖动词 | 绝大多数 | 16 个移动/状态动词 + 代词式动词 |
| 分词配合 | 不配合主语 | **配合主语** |
| 例子 | Elle a mangé. | Elle est allée. |
| 否定 | ne + avoir + pas + 分词 | ne + (代词) + être + pas + 分词 |

## 📖 六、范文：我的一天（过去时）

> Hier, je me suis réveillé à sept heures. Je me suis levé tout de suite. Je suis allé à l'université en métro. J'ai suivi deux cours le matin. À midi, j'ai déjeuné avec un ami. L'après-midi, je suis rentré à la maison et j'ai fait mes devoirs. Le soir, je suis sorti avec des amis. Nous sommes rentrés à minuit. Je me suis couché tout de suite.

**标出助动词**：

| 句子 | 助动词 |
| --- | --- |
| je me suis réveillé | être（代词式） |
| je suis allé | être（aller） |
| j'ai suivi | avoir |
| j'ai déjeuné | avoir |
| je suis rentré | être（rentrer） |
| j'ai fait | avoir（faire 不规则） |
| je suis sorti | être（sortir，无宾语） |
| nous sommes rentrés | être |
| je me suis couché | être（代词式） |

## ✏️ 练习

### 1. 填助动词（avoir / être）并变位

1. Elle ______ (aller) à Paris.
2. Nous ______ (manger) à midi.
3. Ils ______ (arriver) hier.
4. J'______ (finir) mon travail.
5. Elles ______ (partir) tôt.

### 2. 配合

1. Marie est ______ (aller) au marché.
2. Les enfants sont ______ (rester) à la maison.
3. Ma sœur est ______ (naître) en 2005.
4. Nous sommes ______ (rentrer) tard.

### 3. 变代词式动词的过去时

1. Je (se lever) à sept heures. → ______
2. Elle (se coucher) à onze heures. → ______
3. Nous (s'habiller) vite. → ______
4. 否定：Je (se lever) pas tôt. → ______

### 4. 判断用 avoir 还是 être

1. J'______ monté les valises.
2. Je ______ monté au deuxième étage.
3. Elle ______ sorti les poubelles.
4. Elle ______ sortie à huit heures.

<details>
<summary>参考答案</summary>

1. 1. est allée　2. avons mangé　3. sont arrivés　4. ai fini　5. sont parties
2. 1. allée　2. restés　3. née　4. rentrés
3. 1. Je me suis levé(e).　2. Elle s'est couchée.　3. Nous nous sommes habillé(e)s.　4. Je ne me suis pas levé tôt.
4. 1. ai（有宾语 valises）　2. suis（无宾语）　3. a（有宾语 poubelles）　4. est（无宾语）
</details>

## 📌 本周速查

### 词汇

| 法语 | 词性 | 中文 |
| --- | --- | --- |
| arriver | 动词（être） | 到达 |
| partir | 动词（être） | 出发 |
| rentrer | 动词（être） | 回家 |
| rester | 动词（être） | 留下 |
| tomber | 动词（être） | 跌倒 |
| naître | 动词（être） | 出生 |
| mourir | 动词（être） | 死亡 |

| se dépêcher | 代词式动词 | 赶紧 |
| tout de suite | 短语 | 立刻 |

### 语法点

- **16 个 être 动词**：DR MRS VANDERTRAMP，都是移动或状态变化。
- **être 助动词时分词配合主语**：allé / allée / allés / allées。
- **代词式动词的过去**：se 变位 + être + 分词。
- **否定顺序**：ne + 反身代词 + 助动词 + pas + 分词。
- **有直接宾语用 avoir，无宾语用 être**（monter / descendre / sortir）。

---

## ⚠️ 易错点

- `Elle a allé` ❌ → `Elle est allée` ✅
- `Elle est allé` ❌ → `Elle est allée` ✅（漏配合）
- `Ils sont parti` ❌ → `Ils sont partis` ✅
- `Je suis mangé` ❌ → `J'ai mangé` ✅
- `Elle a mangée` ❌ → `Elle a mangé` ✅（avoir 不配合主语）
- `Je me suis levé` 女性漏 e → `levée` ✅
- `Je ne suis pas me levé` ❌ → `Je ne me suis pas levé` ✅
- `Je suis monté les valises` ❌ → `J'ai monté les valises` ✅
- `Je suis né` 写成 `Je suis naî` ❌ → `né` ✅
- `Il est mort` 写成 `Il est mouri` ❌ → `mort` ✅
