# lesson Q
les verbes en "IR"
**les verbes en -IR** = **以 -ir 结尾的动词**。

法语动词根据词尾通常分成三大类：

1. **-ER**：parler（说）
2. **-IR**：finir（完成）
3. **-RE**：prendre（拿）、vendre（卖）等

你现在学的 **-IR 动词**，首先重点掌握最规则的一类，也就是 **finir 类型**。
FINIR finishi
FNIR
- Je fin<mark>is</mark>
- Tu finis
- Il Elle fin<mark>it</mark>
- Nous fin<mark>issons</mark>
- Vous fin<mark>issez</mark>
- Ils/Elles fin<mark>issent</mark>

UNIR
- J'unis
- Tu unis

CHOISIR
Je choisis
### 1. **unir** —— 联合、团结

**unir = to unite / 联合、团结**

它属于比较规则的 **-ir 动词**，现在时变位：

|人称|变位|
|---|---|
|je|**unis**|
|tu|**unis**|
|il / elle|**unit**|
|nous|**unissons**|
|vous|**unissez**|
|ils / elles|**unissent**|

例句：

> **Nous unissons nos forces.**  
> 我们团结我们的力量。

注意它的特点：

**-is, -is, -it, -issons, -issez, -issent**

---

### 2. **choisir** —— 选择

**choisir = to choose / 选择**

也是非常典型的规则 **-ir 动词**：

|人称|变位|
|---|---|
|je|**choisis**|
|tu|**choisis**|
|il / elle|**choisit**|
|nous|**choisissons**|
|vous|**choisissez**|
|ils / elles|**choisissent**|

例句：

> **Je choisis le français.**  
> 我选择法语。

> **Tu choisis quoi ?**  
> 你选择什么？

---

### ⭐ 你现在可以直接记住这个规律

以 **choisir** 为代表：

**choisir → chois- + 词尾**

> je **choisis**  
> tu **choisis**  
> il **choisit**  
> nous **choisissons**  
> vous **choisissez**  
> ils **choisissent**

所以看到很多这种 **-ir 动词**：

> finir（完成）  
> choisir（选择）  
> réussir（成功）  
> grandir（长大）  
> réfléchir（思考）  
> remplir（填满）

可以先尝试套：

**-is / -is / -it / -issons / -issez / -issent**

这是你学习法语 **les verbes en -IR（-IR 动词）**时最重要的一组规律。

## 📌 本课速查

### Lesson I · 指示形容词 ce / cet / cette / ces

| 性 / 数 | 形式 | 使用条件 | 例子 |
| --- | --- | --- | --- |
| 阳性单数 | ce | 辅音开头 | ce train |
| 阳性单数 | cet | 元音或哑音 h 开头 | cet ordinateur, cet homme |
| 阴性单数 | cette | 所有阴性单数 | cette femme |
| 复数 | ces | 阴阳性复数 | ces personnes |

**语法点**

- 指示形容词 = 这个 / 这些；要和名词的性、数配合。
- `cet` 用在元音或哑音 h 开头的阳性单数名词前；`ce` 用在辅音开头前。
- `ces` 阴阳性通用。
- 指示形容词代替冠词：`un train → ce train`，不能说 `le ce train`。
- 例外：`ce héros`（h 是嘘音 h，用 `ce`，不用 `cet`）。

### Lesson J · -er 动词与 aller

**parler（说）**

| 人称 | 变位 |
| --- | --- |
| je | parle |
| tu | parles |
| il/elle | parle |
| nous | parlons |
| vous | parlez |
| ils/elles | parlent |

**regarder（看）**

| 人称 | 变位 |
| --- | --- |
| je | regarde |
| tu | regardes |
| il/elle | regarde |
| nous | regardons |
| vous | regardez |
| ils/elles | regardent |

**aller（去，不规则）**

| 人称 | 变位 |
| --- | --- |
| je | vais |
| tu | vas |
| il/elle | va |
| nous | allons |
| vous | allez |
| ils/elles | vont |

**语法点**

- `-er` 动词现在时：词干 + `-e, -es, -e, -ons, -ez, -ent`。
- `-ent` 不发音：`ils parlent` 听起来像 `il parle`。
- `parler` 词干 `parl-`；`regarder` 词干 `regard-`。
- `aller + 动词原形` = 最近将来时（要去做某事）：`Je vais étudier.` = 我要去学习。
- `aller + 地点`：`Je vais à Paris.` / `Je vais en France.` / `Je vais au Canada.` / `Je vais aux États-Unis.`
- 例句：Je parle français. / Tu regardes la télévision. / Nous allons à l'école.

### Lesson L · venir（来）

| 人称 | 变位 |
| --- | --- |
| je | viens |
| tu | viens |
| il/elle | vient |
| nous | venons |
| vous | venez |
| ils/elles | viennent |

**语法点**

- `venir de + 地点` = 来自某地：`Je viens de France.` = 我来自法国。
- `venir + 地点` = 来某地：`Je viens à Paris.` = 我来巴黎。
- `venir de + 动词原形` = 刚刚做完某事（passé récent）：`Je viens de manger.` = 我刚吃完。
- `venir` 是不规则动词；`ils/elles viennent` 词干变为 `vienn-`。

### Lesson N · 疑问词 qui / que / quoi

| 疑问词 | 问什么 | 位置 | 例子 |
| --- | --- | --- | --- |
| qui | 人 | 句首 / 介词后 | Qui est-il ? / Avec qui ? |
| que | 物 | 句首 | Que fais-tu ? |
| quoi | 物 | 动词后 / 介词后 / 口语 | Tu fais quoi ? / Avec quoi ? |

**语法点**

- `qui` 问人，可作主语或宾语：`Qui vient avec toi ce soir ?`
- `que` 问物，通常放句首：`Que fais-tu ?`
- `quoi` 问物，放动词后或介词后，口语常用：`Tu fais quoi ?`
- 三种等价说法：`Que fais-tu ?` = `Qu'est-ce que tu fais ?` = `Tu fais quoi ?`
- `Que veux-tu regarder à la télévision ?` = 你想在电视上看什么？
- 介词后：人用 `à qui` / `avec qui`；物用 `à quoi` / `avec quoi`。

### Lesson O · 姓名

| 功能 | 正式 | 非正式 |
| --- | --- | --- |
| 问名字 | Comment vous appelez-vous ? / Quel est votre nom ? | Comment tu t'appelles ? / Tu t'appelles comment ? / C'est quoi ton nom ? |
| 回答 | Je m'appelle… / Je suis… / Mon nom est… | 同上 |

**语法点**

- `s'appeler` 是代词式动词：`je m'appelle, tu t'appelles, il/elle s'appelle, nous nous appelons, vous vous appelez, ils/elles s'appellent`。
- 正式问句用倒装：`Comment vous appelez-vous ?`
- 非正式问句不倒装：`Comment tu t'appelles ?`
- `Quel est votre nom ?` 中 `quel` 跟 `nom`（阳性）配合。
- `Je m'appelle…` 最常用；`Je suis…` 也可以；`Mon nom est…` 较正式 / 书面。

### Lesson Q · -ir 动词（finir 型）

**finir（完成）**

| 人称 | 变位 |
| --- | --- |
| je | finis |
| tu | finis |
| il/elle | finit |
| nous | finissons |
| vous | finissez |
| ils/elles | finissent |

**unir（联合）**

| 人称 | 变位 |
| --- | --- |
| j' | unis |
| tu | unis |
| il/elle | unit |
| nous | unissons |
| vous | unissez |
| ils/elles | unissent |

**choisir（选择）**

| 人称 | 变位 |
| --- | --- |
| je | choisis |
| tu | choisis |
| il/elle | choisit |
| nous | choisissons |
| vous | choisissez |
| ils/elles | choisissent |

**语法点**

- 规则 `-ir` 动词（finir 型）：词干 + `-is, -is, -it, -issons, -issez, -issent`。
- 复数词干多 `-iss-`：`nous finissons`、`vous finissez`、`ils finissent`。
- `-ent` 不发音。
- 同类动词：`réussir`（成功）、`grandir`（长大）、`réfléchir`（思考）、`remplir`（填满）。
- 注意：不是所有 `-ir` 动词都这样变；`venir` 就是不规则动词。

## ⚠️ 易错点

- `II` 应为 `Il`，`IIs` 应为 `Ils`（字母 I 误打）。
- `Cet ordinateur`、`Cet homme`：元音 / 哑音 h 开头用 `cet`，不用 `ce`。
- `-er` 动词的 `-ent` 不发音，但拼写不能漏。
- `aller` 不规则：`je vais, tu vas, il va, nous allons, vous allez, ils vont`。
- 21、31、41 用 `et un`；22–29 用连字符。
- `venir` 的 `ils/elles` 形式是 `viennent`。
- `beau-frère` / `belle-sœur` 是姻亲，不是亲兄弟 / 亲姐妹。
- `Que est votre no,?` 应为 `Quel est votre nom ?`
- `la famile` 应为 `la famille`；`situaition` 应为 `situation`。
- `veuf` 的阴性是 `veuve`。
- `choisir` 的 `nous` 形式是 `nous choisissons`，不是 `nous choisisons`。
- `finir` 的 `nous` 形式是 `nous finissons`，不是 `nous finons`。

## 卡片区

阳性单数名词以元音或哑音 h 开头时，用 `ce` 还是 `cet`？::`cet`。例：cet ordinateur, cet homme。

“这些人”的法语？::`ces personnes`。⚠ 易错：`ces` 不分阴阳性。

`-er` 动词现在时的词尾？::`-e, -es, -e, -ons, -ez, -ent`。⚠ 易错：`-ent` 不发音。

`aller + 动词原形` 表示什么？::最近将来时（要去做某事）。例：Je vais étudier。

21、31、41 的法语？::`vingt et un`、`trente et un`、`quarante et un`。⚠ 易错：`et` 前后有空格，不连字符。

`venir de + 地点` 表示什么？::来自某地。例：Je viens de France。

“祖父母 / 父母 / 孩子 / 孙辈”的法语？::`les grands-parents` / `les parents` / `les enfants` / `les petits-enfants`。

`beau-frère` 和 `belle-sœur` 是什么意思？::姻亲兄弟（姐夫 / 妹夫等）；姻亲姐妹（嫂子 / 弟媳等）。⚠ 易错：不是亲兄弟 / 亲姐妹。

`qui / que / quoi` 的区别？::`qui` 问人；`que` 问物（句首）；`quoi` 问物（动词后 / 口语）。

“你在做什么？”的正式说法？::`Que fais-tu ?` / `Qu'est-ce que tu fais ?`

“你叫什么名字？”的正式说法？::`Comment vous appelez-vous ?` / `Quel est votre nom ?`

“我叫……”的三种说法？::`Je m'appelle…` / `Je suis…` / `Mon nom est…`

`s'appeler` 的 `je / tu / il` 形式？::`je m'appelle, tu t'appelles, il/elle s'appelle`。

“单身 / 已婚 / 离婚 / 丧偶”的法语？::`célibataire` / `marié(e)` / `divorcé(e)` / `veuf (veuve)`。

`veuf` 的阴性形式？::`veuve`。

`finir` 型 `-ir` 动词的现在时词尾？::`-is, -is, -it, -issons, -issez, -issent`。

`choisir` 的 `nous` 形式？::`nous choisissons`。⚠ 易错：不是 `nous choisisons`。

“我选择法语”用法语怎么说？::`Je choisis le français`。

“我们团结我们的力量”用法语怎么说？::`Nous unissons nos forces`。
