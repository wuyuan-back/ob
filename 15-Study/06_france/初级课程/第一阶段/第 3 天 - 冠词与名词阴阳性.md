## 📖 一、名词的阴阳性

法语所有名词分**阳性（masculin）**和**阴性（féminin）**。这是语法性别，跟"男人女人"没关系——`la table`（桌子）是阴性，`le livre`（书）是阳性。

### 为什么重要

形容词、冠词、代词都要跟着名词的性变：

- `un petit chat`（阳性）→ `une petite maison`（阴性）
- `le` / `la`、`mon` / `ma`、`ce` / `cette`

### 怎么记

**唯一可靠的办法：背单词时连冠词一起背。**

| ❌ 不要这样 | ✅ 要这样 |
| --- | --- |
| livre = 书 | un livre = 一本书 |
| table = 桌子 | une table = 一张桌子 |
| problème = 问题 | un problème = 一个问题 |

### 简单的规律（不完全可靠，但能帮一半）

| 词尾 | 多为 | 例外 |
| --- | --- | --- |
| -age, -ment, -eau, -isme | 阳性 | la plage（海滩）、la page（页） |
| -tion, -sion, -té, -ette, -ance, -ence | 阴性 | un été（夏天） |
| -eur | 多为阳性 | la fleur（花） |
| -ure | 阴性 | — |

> 规律只能救急。**遇到新词，一律查词典确认。**

---

## 📖 二、定冠词：the

| | 阳性 | 阴性 |
| --- | --- | --- |
| 单数 | **le** livre | **la** table |
| 元音/哑音 h 开头 | **l'** ami | **l'** école |
| 复数 | **les** livres | **les** tables |

- `le / la` 在**元音或哑音 h 开头**的名词前省音成 **`l'`**，不分阴阳性：`l'ami`、`l'école`、`l'homme`、`l'hôtel`。
- `les` 接元音开头的词要联诵：`les amis` [lez‿ami]。

---

## 📖 三、不定冠词：a / some

| | 阳性 | 阴性 |
| --- | --- | --- |
| 单数 | **un** livre | **une** table |
| 复数 | **des** livres | **des** tables |

- `un` = 一个（阳），`une` = 一个（阴），`des` = 一些（不分性）。
- **不定冠词不省音**：`un ami`，不是 `un n'ami`。
- 否定句里 `un / une / des` 通常变成 **`de`**（第 5 天细讲）：`Je n'ai pas **de** frère.`

---

## 📖 四、什么时候用哪个

| 场景 | 用 | 例子 |
| --- | --- | --- |
| 第一次提到、一个不确定的 | 不定冠词 | J'ai **un** chat. 我有一只猫。 |
| 已经提过、特指 | 定冠词 | **Le** chat est noir. 这只猫是黑的。 |
| 表示整类 | 定冠词 | J'aime **le** café. 我喜欢咖啡（这类东西）。 |
| 职业、身份 | **不用冠词** | Je suis étudiant. |
| 国家名（大多数） | 定冠词 | la France, le Canada |

**对比**：

- `Je cherche un livre.` 我在找一本书（随便哪本）。
- `Je cherche le livre.` 我在找那本书（特定的那本）。

## 📖 五、名词复数

### 规则一：一般加 -s

| 单数 | 复数 | 读音 |
| --- | --- | --- |
| un livre | des livres | 读音不变 |
| une table | des tables | 读音不变 |
| un étudiant | des étudiants | 读音不变 |

**复数的 `-s` 不发音**，所以口语里单复数经常听不出来，靠冠词 `le/la` vs `les` 区分。

### 规则二：-al → -aux

| 单数 | 复数 |
| --- | --- |
| un journal | des journaux |
| un hôpital | des hôpitaux |
| un animal | des animaux |

### 规则三：本来以 -s / -x / -z 结尾的，复数不变

| 单数 | 复数 |
| --- | --- |
| un fils | des fils |
| une voix | des voix |
| un nez | des nez |

> `-eau / -au / -eu` 加 `-x`、`-ou` 的七个例外加 `-x`，这些在 [[Unit3]] Lesson A 已经系统学过，这里不重复。

### 形容词也要跟着变

| | 阳性单数 | 阴性单数 | 阳性复数 | 阴性复数 |
| --- | --- | --- | --- | --- |
| 大 | grand | grand**e** | grand**s** | grand**es** |
| 小 | petit | petit**e** | petit**s** | petit**es** |
| 漂亮 | beau | bell**e** | beau**x** | bell**es** |

> 形容词的阴阳性变化（`beau → belle`、`vieux → vieille`）第 4 天之后系统讲，今天先知道"要变"。

## 📌 本课速查

### 词汇

| 法语（带冠词） | 阴阳性 | 中文 | 例句 |
| --- | --- | --- | --- |
| un livre | 阳性 | 书 | J'ai un livre. |
| une table | 阴性 | 桌子 | La table est grande. |
| une école | 阴性 | 学校 | Je vais à l'école. |
| un ami / une amie | 阳 / 阴 | 朋友 | C'est un ami. |
| un homme | 阳性 | 男人 | L'homme est grand. |
| une femme | 阴性 | 女人 | La femme est française. |
| un journal | 阳性 | 报纸 | Je lis le journal. |
| une photo | 阴性 | 照片 | C'est une photo. |
| un problème | 阳性 | 问题 | C'est un problème. |
| une question | 阴性 | 问题（提问） | J'ai une question. |

### 语法点

- **阴阳性靠冠词体现**：`un/le` = 阳，`une/la` = 阴。
- **`le/la` 在元音或哑音 h 前省音成 `l'`**：`l'ami`、`l'école`、`l'homme`。
- **`un/une/des` 是"一个/一些"**；`le/la/les` 是"这个/这些"或表示整类。
- **职业前不用冠词**：`Je suis étudiant.`
- **复数**：一般 +`s`；-al → -aux；本身以 -s/-x/-z 结尾不变。
- **复数 -s 不发音**，靠冠词区分单复数。

---

## ⚠️ 易错点

- 背单词只背词干不背冠词——之后每次用都要重新查性。
- `le école` ❌ → `l'école` ✅（元音开头必须省音）
- `un amie` ❌ → `une amie` ✅（阴性命词用 une）
- `des journal` ❌ → `des journaux` ✅（-al → -aux）
- `Je suis un étudiant` 不自然 → `Je suis étudiant` ✅
- `un problème` 是**阳性**，不是根据 -e 结尾猜成阴性。
- 名词 `problème`（问题）和 `question`（问题）性不同：`un problème` / `une question`。
