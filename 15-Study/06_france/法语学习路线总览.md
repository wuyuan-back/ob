## 🅰️ 阶段一 · A1（12 周）

### 目标

不是"会很多"，而是**看见中文能自己造出法语句子**：

> 我今天在学校学习。 → `J'étudie à l'université aujourd'hui.`

而不是「中文 → 翻译软件 → 法语」。

### 语法清单

- 发音：字母、鼻化元音、`r`/`u`/`ou`、联诵、词尾辅音规则
- 两个地基动词：`être`、`avoir`
- 名词阴阳性 + 定冠词 / 不定冠词 / 部分冠词
- 形容词性数配合与位置
- 现在时：`-er` 规则动词 + 高频不规则动词（aller, faire, prendre, venir, pouvoir, vouloir, devoir）
- 否定（ne…pas / jamais / rien / plus / personne）
- 疑问（语调 / est-ce que / 倒装）+ 疑问词
- 主有形容词、指示形容词
- 复合过去时（avoir + être 两类助动词）
- 最近将来（aller + 不定式）、最近过去（venir de + 不定式）
- 宾语代词入门（le/la/les, lui/leur, y, en）
- 时间、日期、天气、数字 0–100

### 验收标准（全部满足才进 A2）

- [ ] 不看稿做 2 分钟自我介绍 + 回答 5 个追问
- [ ] 默写 être / avoir / aller / faire 四个动词的六人称变位
- [ ] 给一个名词能说出冠词、复数、形容词配合三件事
- [ ] 复合过去时：正确选择 avoir / être 助动词，正确配合
- [ ] 听懂 1 分钟 A1 语速对话，抓住人物、地点、时间三个要素
- [ ] 写 80 词短文（自我介绍 + 上周做了什么），错误 ≤5 处
- [ ] DELF A1 模拟卷 ≥ 60/100

## 🅱️ 阶段二 · A2（16 周）

### 目标

从「造句」升级到「连续表达」。A1 说 `J'aime Paris.`，A2 要能说：

> `J'aime Paris parce que c'est une ville très intéressante. Il y a beaucoup de choses à faire.`

核心是**连接思想**：`parce que / mais / donc / cependant / quand / si`。

### 分块排期

| 周次 | 模块 | 内容 |
| --- | --- | --- |
| 1–4 | 时态补齐 | 未完成过去时（imparfait）、简单将来时、过去时对比 |
| 5–8 | 代词与比较 | y / en 深化、直接与间接宾语代词综合、比较级与最高级 |
| 9–12 | 连接与从句 | 逻辑连接词、关系代词 qui/que/où、si 条件句 |
| 13–16 | 综合冲刺 | 四技能训练 + 主题词汇（旅行、健康、购物、媒体）+ DELF A2 模拟 |

### 验收标准

- [ ] 就一个熟悉话题连续说 2 分钟，结构完整
- [ ] 会用 imparfait 描述背景、用复合过去时叙述事件
- [ ] 正确使用 y / en 回答"去不去""有没有"
- [ ] 写 120–150 词记叙文，时态不混
- [ ] DELF A2 模拟卷 ≥ 60/100

## 🅲 阶段三 · B1（20 周）

### 目标

**从"描述"进入"论证"。** 被问 `Est-ce qu'il est important d'apprendre une langue étrangère ?` 时，能走完这条链：

```
提出观点 → 解释原因 → 举例 → 提出反方 → 总结
```

### 分块排期

| 周次 | 模块 | 内容 |
| --- | --- | --- |
| 1–4 | 虚拟式 | 虚拟式现在时（触发词、形式、常用句型） |
| 5–8 | 复杂句 | 关系代词 dont、被动语态、间接引语 |
| 9–12 | 时态进阶 | 愈过去时、时态配合、si + imparfait 假设句 |
| 13–16 | 观点表达 | 论证框架、连接词升级、议论文写作 |
| 17–20 | 冲刺 | 新闻听力、长文阅读、DELF B1 全真模拟 |

### 验收标准

- [ ] 就抽象话题（教育、环境、科技）说 3 分钟，有论点有例子
- [ ] 写作 160–180 词议论文，结构清晰
- [ ] 读懂 400 词新闻，能复述主旨与细节
- [ ] 听懂正常语速广播，抓住 70% 信息
- [ ] DELF B1 模拟卷 ≥ 60/100

## 🅳 阶段四 · B2（24 周）

### 目标

**长篇口语 + 抽象话题 + 辩论。** 能听懂带口音的访谈，能就同一议题站两个立场各说一遍。

### 分块排期

| 周次 | 模块 | 内容 |
| --- | --- | --- |
| 1–6 | 高阶语法 | 虚拟式过去时、分词式、复杂从属结构 |
| 7–12 | 输入强化 | 新闻、访谈、长文、学术文本；主题词汇扩展到 6000 |
| 13–18 | 输出强化 | 论证写作、辩论、口头报告、改稿循环 |
| 19–24 | 冲刺 | DELF B2 全真模拟 + 弱项专项 |

### 验收标准

- [ ] 就争议话题做 5 分钟即兴陈述并应对追问
- [ ] 写 250 词议论文，论证有层次、连接词自然
- [ ] 听懂访谈类音频，能总结双方立场
- [ ] DELF B2 模拟卷 ≥ 60/100

## 🗓️ 每周节奏模板

每周 6 天学习 + 1 天复盘，单日 90–120 分钟：

| 时段 | 时长 | 做什么 |
| --- | --- | --- |
| 复习 | 15 分钟 | Anki 到期卡，**先复习再学新** |
| 语法 | 25 分钟 | 当周笔记的一个小节，做配套练习 |
| 词汇 | 15 分钟 | 10 个新词，每个词造一句自己的句子 |
| 听力 | 20 分钟 | 精听 1 段（听写 → 对照 → 跟读） |
| 口语 | 15 分钟 | 录音 1–2 分钟，回听找错 |
| 收尾 | 10 分钟 | 错题写进错误数据库 |

**周六**：输出日——写作一篇 + 录音一段，不学新内容。
**周日**：周测 + 把本周错题重做一遍 + 预习下周主题。

> 时间不够时按这个顺序砍：听力 → 口语 → 词汇。**语法和复习不能砍。**

---

## 🔁 复习系统

三层，缺一层就会"学完就忘"：

1. **Anki**（每日）— 卡片来自各篇笔记的「卡片区」，见 [[Anki发音说明]]
2. **周测**（每周日）— 每篇周笔记末尾的自测题 + 上周错题
3. **错误数据库**（持续）— 单独一篇笔记，记录"我错过什么、为什么错、正确形式"

> 错误数据库比新笔记重要。同一个错误犯三次，说明是理解问题，不是记忆问题。

## ⚠️ 三条最容易走偏的地方

1. **只学不练**：看完笔记不做练习 = 没学。每节至少做完「练习」再往下。
2. **跳过发音**：A1 阶段发音定型，B2 再改成本极高。第 1 周的发音规则要反复回看。
3. **用翻译软件写作业**：写作练习的价值就在"自己写错再改"，翻译软件会把这个环节整段抹掉。
