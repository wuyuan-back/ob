# 大学物理期末复习手册：电磁学部分

## 第五章：真空中的静电场

### 1. 库仑定律与叠加原理

- **库仑定律**：$\vec{F}_{21} = \frac{1}{4\pi\varepsilon_0} \frac{q_1 q_2}{r^2} \vec{e}_{21}$
    
- **电场强度定义**：$\vec{E} = \frac{\vec{F}}{q_0}$
    
- **点电荷场强**：$E = \frac{1}{4\pi\varepsilon_0} \frac{q}{r^2}$
    
- **场强叠加原理**：$\vec{E} = \sum \vec{E}_i = \int \frac{dq}{4\pi\varepsilon_0 r^2} \vec{e}_r$
    

### 2. 高斯定理（通量与源的关系）

- **电通量**：$\Phi_e = \oint_S \vec{E} \cdot d\vec{S}$
    
- **高斯定理**：$\oint_S \vec{E} \cdot d\vec{S} = \frac{\sum q_{in}}{\varepsilon_0}$
    
    - _应用提示_：处理具有球对称、轴对称（无限长柱）、平面对称的带电体时，优先使用此定理。
        

### 3. 静电场的环路定理与电势

- **环路定理**：$\oint_L \vec{E} \cdot d\vec{l} = 0$（表明静电场是保守场/有势场）。
    
- **电势定义**：$V_a = \int_a^{\infty} \vec{E} \cdot d\vec{l}$（以无穷远处为零势点）。
    
- **点电荷电势**：$V = \frac{1}{4\pi\varepsilon_0} \frac{q}{r}$
    
- **电势叠加**：$V = \sum V_i = \int \frac{dq}{4\pi\varepsilon_0 r}$
    
- **电场与电势梯度**：$\vec{E} = -\nabla V$（场强等于电势梯度的负值，指向电势降低最快的方向）。
    

## 第六章：静电场中的导体与电介质

### 1. 导体的静电平衡

- **平衡条件**：内部 $E_{内} = 0$；表面 $E_{表} \perp$ 表面。
    
- **性质**：导体是等势体，表面是等势面；电荷仅分布在表面。
    
- **表面场强与面密度**：$E = \frac{\sigma}{\varepsilon_0}$
    

### 2. 电介质与极化

- **电极化强度**：$\vec{P} = \frac{\sum \vec{p}}{\Delta V} = \chi_e \varepsilon_0 \vec{E}$
    
- **束缚电荷与极化的关系**：$\sigma' = \vec{P} \cdot \vec{n}$
    
- **介质中的高斯定理**：$\oint_S \vec{D} \cdot d\vec{S} = \sum q_f$（右侧仅包含**自由电荷**）。
    
- **三个矢量的关系**：$\vec{D} = \varepsilon_0 \vec{E} + \vec{P} = \varepsilon \vec{E}$
    

### 3. 电容与电容器

- **电容定义**：$C = \frac{q}{V}$（孤立导体）或 $C = \frac{Q}{U}$（电容器）。
    
- **经典电容公式**：
    
    1. **平行板**：$C = \frac{\varepsilon S}{d}$
        
    2. **球形**：$C = \frac{4\pi\varepsilon R_1 R_2}{R_2 - R_1}$
        
    3. **柱形**：$C = \frac{2\pi\varepsilon l}{\ln(R_2/R_1)}$
        
- **储能公式**：$W = \frac{1}{2} C U^2 = \frac{Q^2}{2C}$
    
- **能量密度**：$w_e = \frac{1}{2} \vec{D} \cdot \vec{E} = \frac{1}{2} \varepsilon E^2$
    

## 第七章：恒定磁场

### 1. 毕奥-萨伐尔定律

- **基本公式**：$d\vec{B} = \frac{\mu_0}{4\pi} \frac{I d\vec{l} \times \vec{e}_r}{r^2}$
    
- **典型磁场**：
    
    - **无限长直导线**：$B = \frac{\mu_0 I}{2\pi a}$
        
    - **圆电流中心**：$B = \frac{\mu_0 I}{2R}$
        
    - **无限长螺线管内部**：$B = \mu_0 n I$
        

### 2. 磁场的基本定理

- **磁场高斯定理**：$\oint_S \vec{B} \cdot d\vec{S} = 0$（磁场是无源场，不存在磁单极子）。
    
- **安培环路定理**：$\oint_L \vec{B} \cdot d\vec{l} = \mu_0 \sum I_{in}$（磁场是有旋场）。
    
    - _介质中形式_：$\oint_L \vec{H} \cdot d\vec{l} = \sum I_{f,in}$（右侧为自由电流）。
        
    - _关系式_：$\vec{B} = \mu \vec{H}$
        

### 3. 磁场对电荷与电流的作用

- **洛伦兹力**：$\vec{F} = q\vec{v} \times \vec{B}$
    
    - _运动半径_：$R = \frac{mv}{qB}$；_周期_：$T = \frac{2\pi m}{qB}$
        
- **安培力**：$d\vec{F} = I d\vec{l} \times \vec{B}$
    
- **磁力矩**：$\vec{\tau} = \vec{m} \times \vec{B}$（其中磁矩 $\vec{m} = I\vec{S}$）。
    

## 第八章：变化的电磁场

### 1. 法拉第电磁感应定律

- **基本方程**：$\mathcal{E} = -\frac{d\Phi_m}{dt}$
    
    - _负号意义_：楞次定律，感应电流的效果总是阻碍引起感应的磁通量变化。
        

### 2. 动生与感生电动势

- **动生电动势**：$\mathcal{E}_i = \int (\vec{v} \times \vec{B}) \cdot d\vec{l}$（导体运动切割磁感线）。
    
- **感生电动势**：$\mathcal{E}_i = \oint \vec{E}_k \cdot d\vec{l} = -\iint \frac{\partial \vec{B}}{\partial t} \cdot d\vec{S}$
    
    - _感生电场（涡旋电场）_：$\oint \vec{E}_k \cdot d\vec{l} = -\frac{d\Phi_m}{dt}$。注意感生电场是非保守场，线积分不为零。
        

### 3. 自感与互感

- **自感**：$\Psi = LI$；$\mathcal{E}_L = -L \frac{dI}{dt}$
    
- **互感**：$\Psi_{21} = M I_1$；$\mathcal{E}_{21} = -M \frac{dI_1}{dt}$
    
- **磁场能量**：$W_m = \frac{1}{2} L I^2$
    
- **磁能密度**：$w_m = \frac{1}{2} \vec{B} \cdot \vec{H} = \frac{B^2}{2\mu}$
    

## 典型问题模型总结（考前必看）

1. **接地导体球镜像电荷**：镜像电荷量 $q' = -(R/d)q$，位置 $b = R^2/d$。球面感应总电荷即为 $q'$。
    
2. **同心带电球面电势**：
    
    - $r < R_1$：$V = \frac{Q_1}{4\pi\varepsilon_0 R_1} + \frac{Q_2}{4\pi\varepsilon_0 R_2}$
        
    - $R_1 < r < R_2$：$V = \frac{Q_1}{4\pi\varepsilon_0 r} + \frac{Q_2}{4\pi\varepsilon_0 R_2}$
        
3. **平行板电场叠加**：两板带等量同号电荷 $+\sigma$，板间 $E=0$；带等量异号电荷，板间 $E = \sigma/\varepsilon_0$。
    
4. **切断圆环的电压**：开路电压等于总感生电动势 $U = |\mathcal{E}|$；闭合均匀圆环内部任意两点电势差为 0。
